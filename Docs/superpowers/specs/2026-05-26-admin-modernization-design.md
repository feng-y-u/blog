# 后台管理系统现代化改造设计文档

> **创建日期**：2026-05-26
> **状态**：定稿

## 1. 概述

### 目标
对现有后台管理系统进行现代化改造，核心是引入 BlockNote 块编辑器替代 textarea，同时统一所有管理页面的视觉风格。

### 范围
- **编辑器**：用 BlockNote 块编辑器替换当前 textarea + 实时预览
- **后台 UI**：所有管理页面重新设计，统一深色侧边栏 + 白色内容区
- **MD 上传**：编辑器支持上传 .md 文件自动解析为块；笔记管理页改进上传+一键转文章
- **图片**：编辑器内拖拽/点击上传图片，保持现有上传接口

### 非范围
- 后台功能不增减（没有新 CRUD、没有新页面）
- 前台展示完全不变（仍用 react-markdown 渲染）
- 数据库 Schema 不变
- 认证逻辑不变

## 2. 技术方案

### 2.1 BlockNote 集成

使用 `@blocknote/react` + `@blocknote/core` + `@blocknote/mantine` (v0.50+)。

**数据流：**
```
保存: BlockNote Editor → editor.blocksToMarkdownLossy() → Markdown → DB
加载: DB → Markdown → editor.tryParseMarkdownToBlocks() → BlockNote Editor
前台: DB → Markdown → react-markdown（不变）
```

**为什么不存 BlockNote JSON？** 用户要求保持现有数据格式。且块类型少（文字+媒体），Markdown round-trip 无损。

**已有文章兼容：** 全部自动兼容。首次打开编辑器时，Markdown → 块转换，保存时块 → Markdown 回写。

### 2.2 块类型

| 类别 | 块类型 | BlockNote 原生支持 |
|------|--------|-------------------|
| 文字 | 段落、H1-H3、引用、有序列表、无序列表、待办列表 | ✅ |
| 媒体 | 图片、代码块、分割线 | ✅ |

无需自定义块类型，BlockNote 原生覆盖全部需求。

### 2.3 后台视觉规范

- **侧边栏**：深色底 #1a1a2e，文字白色/半透明白，当前页高亮
- **内容区**：白色/浅色背景，卡片白底细边框
- **统一组件**：.admin-card、.admin-table、.admin-btn、.admin-badge
- **图标**：导航项使用 emoji 增强可识别性
- **暗色模式**：侧边栏跟随 CSS 变量自适应

### 3.2 块编辑器布局

编辑器区域占左 70%，右侧元数据面板占右 30%：

```
┌─ Title: [文章标题输入框] ──────────────────────────┐
│─ Toolbar: B I U | H1 H2 引用 代码 列表 | 🖼️ 📄 .md │
│─ BlockNote Editor ────────────────────────────────│
│  ┌── block 1: 标题文字 ────────────────────────┐  │
│  └─────────────────────────────────────────────┘  │
│  ┌── block 2: 段落文字 ────────────────────────┐  │
│  └─────────────────────────────────────────────┘  │
│  ┌── block 3: 图片块 ──────────────────────────┐  │
│  └─────────────────────────────────────────────┘  │
│  ┌── block 4: 代码块 ──────────────────────────┐  │
│  └─────────────────────────────────────────────┘  │
│  [ + / 命令插入块 ]                               │
│─ Bottom: [保存草稿] [发布] Ctrl+S ─────────────────│
│  ┌─ 右侧面板 ───────────────────────────────────┐ │
│  │  分类 / 标签 / 封面图 / 装饰字                │ │
│  └──────────────────────────────────────────────┘ │
```

### 3.3 笔记管理布局

左侧笔记列表（200px）+ 右侧预览/编辑区，底部操作栏（编辑/转为文章/导出/删除）。

## 5. 注意事项

- BlockNote Mantine 主题通过 CSS 变量适配现有暗色模式
- 现有图片上传接口和 URL 格式不变，BlockNote 通过自定义图片上传按钮集成
- .md 文件上传用 FileReader 读取内容，调用 `tryParseMarkdownToBlocks()` 解析后插入编辑器
- "笔记转文章"在 NoteManager 中读取笔记内容后 navigate 到 PostEditor 并预填充
