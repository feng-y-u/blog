# Editorial Magazine 首页改版设计

## 项目概述

将博客首页从传统列表式改版为「编辑杂志」风格，采用全屏分栏跨页布局、动态文字动效、日系视觉语言。浅色模式默认，粉色+青色双色方案。

## 视觉设计

### 色彩（浅色模式默认）

| 用途 | 色值 | 说明 |
|------|------|------|
| 背景 | `#fff` / `#fafafc` | 主背景 / 右侧视觉区 |
| 标题文字 | `#1a1a1a` | 主标题 |
| 正文 | `#666` | 文章正文 |
| 弱化文字 | `#bbb` | 日期、阅读时间 |
| 分隔线 | `#f0f0f0` | 极淡灰 |
| **粉色** | `#e85d8a` | 分类标签、标签边框、代码关键字、引用框、悬浮态 |
| **青色** | `#0099cc` | 代码变量/函数、次要链接 |
| 日文大文字 | `rgba(232,93,138,0.06)` | 右侧视觉元素 |

### 右侧视觉

双层叠加：
- **底层**：Canvas 粒子动画，30-50 个粉色/青色粒子缓慢浮动
- **上层**：超大日文文字（`font-size: 100px`，`opacity: 0.06`），每篇文章对应一个关键词

粒子实现：自写轻量 Canvas（约 50 行），不引入第三方库。粒子颜色按文章主题切换。

### 字体排印

| 层级 | 大小 | 字重 | 行高 |
|------|------|------|------|
| 首屏标题 | 36px | 800 | 1.1 |
| 详情页标题 | 32px | 800 | 1.15 |
| 正文 | 13px | 400 | 1.9 |
| 代码 | monospace | 400 | 1.6 |
| 元信息 | 10px | 400 | — |

## 动效（重度）

使用 GSAP + ScrollTrigger + SplitText

| 动效 | 说明 |
|------|------|
| 标题 scramble | 滚动时文字从乱码 → 可读 |
| Parallax split | 左右两侧以不同速度/方向入场 |
| Snap scroll | 跨页之间吸附滚动 |
| 背景渐变 | 滚动时背景色缓慢变化 |
| 逐字显现 | SplitText 字母逐个出现 |
| 点击过渡 | 点文章时标题「放大填充」到详情页 |
| 粒子浮动 | Canvas 粒子缓慢上下飘动 |
