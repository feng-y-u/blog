# Python 特性（二）：生成器与迭代器

通过列表生成式可以直接创建一个列表。但列表容量受内存限制，如果元素可以按某种算法推算出来，就可以在循环中**不断推算后续元素**，而不必创建完整的 list——这正是**生成器**的用途。

## 生成器（Generator）

**生成器**：一边循环一边计算，而不必生成完整的 list，从而**节省大量空间**。

### 创建生成器：把 `[]` 改为 `()`

创建方法一：把一个列表生成式的 `[]` 改为 `()`，就创建了一个生成器：

```python
>>> L = [x * x for x in range(10)]
>>> L
[0, 1, 4, 9, 16, 25, 36, 49, 64, 81]
>>> g = (x * x for x in range(10))
>>> g
<generator object <genexpr> at 0x1022ef630>
```

`L` 是一个 list，而 `g` 是一个 **generator 对象**。

要看到生成器生成的值，可以调用 `next(g)` 逐个获取，更常用的是使用 for 循环（生成器也是可迭代对象）：

```python
>>> g = (x * x for x in range(10))
>>> for n in g:
...     print(n)
...
0
1
4
9
16
25
36
49
64
81
```

### 创建生成器：generator 函数（yield）

当算法比较复杂、列表生成式不能胜任时，就要使用**函数**来实现。比如斐波那契数列：

```python
def fib(max):
    n, a, b = 0, 0, 1
    while n < max:
        print(b)
        a, b = b, a + b
        n = n + 1
    return 'done'
```

> **补充：Python 多重赋值的执行顺序**
> `a, b = b, a + b` 并不是先执行 `a = b`，再执行 `b = a + b`。它的实际过程是：
> 1. **先计算右侧的所有表达式**，得到一个元组 `(b, a + b)`，此时用的都是**旧值**；
> 2. **再把这个元组拆开，按顺序赋给左侧的变量**：`a` 得到旧 `b`，`b` 得到旧 `a + 旧 b`。
> 因此，`b = a + b` 中的 `a` 是**原来的 `a`**，而不是已经被覆盖后的 `a`。

要把 `fib` 函数变成 generator 函数，只需要把 `print(b)` 改为 `yield b`：

```python
def fib(max):
    n, a, b = 0, 0, 1
    while n < max:
        yield b
        a, b = b, a + b
        n = n + 1
    return 'done'
```

**generator 函数和普通函数的执行流程不一样**：

- 普通函数**顺序执行**，遇到 `return` 语句（或最后一行函数语句）就返回；
- generator 函数在**每次调用 `next()` 时执行**，遇到 `yield` 语句就**返回**，并且**再次执行时从上次返回的 yield 语句处继续执行**。

几个要点：

- 调用 generator 函数会创建一个 **generator 对象**，多次调用会创建多个**相互独立的 generator 对象**。
- 创建 generator 对象后，不断对**同一个对象**调用 `next()`，就可以从上次 `next()` 的位置继续执行。
- generator 函数执行时每次调用都会在 `yield` 处中断，所以一般都使用 **for 循环**进行迭代：

```python
>>> for n in fib(6):
...     print(n)
...
1
1
2
3
5
8
```

### 拿不到 return 的返回值？捕获 StopIteration

for 循环调用 generator 是**拿不到 `return` 的返回值**的。当生成器执行到 `return` 时，它会抛出 `StopIteration` 错误，异常对象携带该返回值。

所以要拿到返回值，必须捕获 `StopIteration` 错误，返回值包含在 `StopIteration` 的 `value` 属性中：

```python
>>> g = fib(6)
>>> while True:
...     try:
...         x = next(g)
...         print('g:', x)
...     except StopIteration as e:
...         print('Generator return value:', e.value)
...         break
...
g: 1
g: 1
g: 2
g: 3
g: 5
g: 8
Generator return value: done
```

## 迭代器（Iterator）

已经知道，可以直接作用于 for 循环的数据类型有两大类：

- 一类是**集合数据类型**，如 `list`、`tuple`、`dict`、`set`、`str` 等；
- 一类是 **generator**，包括生成器表达式和带 `yield` 的 generator 函数。

这些统称为**可迭代对象：Iterable**。

可以使用 `isinstance()` 判断一个对象是否是 Iterable 对象：

```python
>>> from collections.abc import Iterable
>>> isinstance([], Iterable)
True
>>> isinstance({}, Iterable)
True
>>> isinstance('abc', Iterable)
True
>>> isinstance((x for x in range(10)), Iterable)
True
>>> isinstance(100, Iterable)
False
```

而**迭代器（Iterator）**是指：可以被 `next()` 函数不断调用并返回下一个值的对象。生成器不仅可以作用于 for 循环，还可以被 `next()` 不断调用、直到抛出 `StopIteration`，所以**生成器都是 Iterator**：

```python
>>> from collections.abc import Iterator
>>> isinstance((x for x in range(10)), Iterator)
True
>>> isinstance([], Iterator)
False
>>> isinstance({}, Iterator)
False
>>> isinstance('abc', Iterator)
False
```

**generator 都是 Iterator 对象，但 `list`、`dict`、`str` 等虽然是 Iterable，却不是 Iterator。**

可以使用 `iter()` 函数，将 `list`、`dict`、`str` 等 Iterable 对象变成 Iterator：

```python
>>> isinstance(iter([]), Iterator)
True
```

### 小结

1. 凡是**可作用于 for 循环**的对象都是 **Iterable** 类型；
2. 凡是**可作用于 `next()` 函数**的对象都是 **Iterator** 类型，它表示一个**惰性计算**的序列；
3. 集合数据类型（`list`、`dict`、`str` 等）是 Iterable 但不是 Iterator，不过可以通过 `iter()` 函数获得一个 Iterator 对象；
4. **Python 的 for 循环本质上就是通过不断调用 `next()` 实现的**——对普通 Iterable，for 循环先用 `iter()` 拿到 iterator，再不断 `next()`，直到 `StopIteration` 结束。
