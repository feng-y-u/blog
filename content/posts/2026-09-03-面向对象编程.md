# Python 面向对象编程：类与实例、封装、继承与多态、对象信息

**面向对象编程**（Object Oriented Programming，OOP）是一种程序设计思想，把**对象**作为程序的基本单元，一个对象包含了**数据**和**操作数据的函数**。

面向对象的程序设计把计算机程序视为一组**对象的集合**：每个对象都可以接收其他对象发过来的消息，并处理这些消息，计算机程序的执行就是一系列消息在各个对象之间传递。

```python
class Student(object):
    def __init__(self, name, score):
        self.name = name
        self.score = score

    def print_score(self):
        print('%s: %s' % (self.name, self.score))
```

这是一个表示学生的类，有**名字**和**成绩**两个属性。`__init__` 是对象被创建时**自动调用**的初始化方法；`self` 是给内部函数使用的参数（指向实例本身）。

面向对象有三大特点：**数据封装、继承和多态**。

## 类和实例

以上面的学生类为例：

- 使用 `class` 定义类，**类名一般为大写开头的单词**；
- `(object)` 表示该类从哪里继承。通常，如果没有合适的继承类，就使用 `object` 类——这是所有类最终都会继承的类。

`__init__` 方法的第一个参数永远是 `self`，表示**创建的实例本身**，因此在方法内部，可以把各种属性绑定到 `self`，毕竟 `self` 就指向创建的实例本身。

在类中定义的函数只有一点不同：**第一个参数永远是实例变量 `self`，并且调用时不用传递该参数**。除此之外，类的方法和普通函数没有什么区别：

```python
>>> bart = Student('Bart Simpson', 59)
>>> bart.print_score()
Bart Simpson: 59
```

## 数据封装

以上面的学生类为例：每个实例都有自己的属性，我们可以通过函数来访问数据。

**数据封装**就是在类的内部定义好访问数据的函数，这些封装数据的函数也被称为**类的方法**。

- 要定义一个方法，除了第一个参数是 `self` 外，其他和普通函数一样；
- 要调用一个方法，只需要在**实例变量上直接调用**，除了 `self` 不用传递，其他参数正常传入。

### 小结

- 类是创建实例的**模板**，而实例则是一个一个具体的**对象**，各个实例拥有的数据都互相独立，互不影响；
- **方法就是与实例绑定的函数**，和普通函数不同，方法可以直接访问实例的数据；
- 通过在实例上调用方法，我们就直接操作了对象内部的数据，但无需知道方法内部的实现细节。

### 实例可以动态绑定属性

和静态语言不同，Python **允许对实例变量绑定任何数据**。也就是说，对于两个实例变量，虽然它们都是同一个类的不同实例，但拥有的变量名都可能不同：

```python
>>> bart = Student('Bart Simpson', 59)
>>> lisa = Student('Lisa Simpson', 87)
>>> bart.age = 8
>>> bart.age
8
>>> lisa.age
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
AttributeError: 'Student' object has no attribute 'age'
```

可以看出，Python 的对象模型**允许对象在运行时灵活地添加或修改属性**。

## 访问限制

外部代码可以直接调用实例变量来操作数据。如果要让内部属性**不被外部访问**，可以把属性的名字前加上**两个下划线 `__`**，把属性变成**私有变量**：

```python
class Student(object):
    def __init__(self, name, score):
        self.__name = name
        self.__score = score

    def print_score(self):
        print('%s: %s' % (self.__name, self.__score))
```

改完后，就不能从外部访问 `__name` 和 `__score` 了：

```python
>>> bart = Student('Bart Simpson', 59)
>>> bart.__name
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
AttributeError: 'Student' object has no attribute '__name'
```

如果外部代码要获得或修改 name 和 score，就给 Student 类增加 **get 方法和 set 方法**。使用类内封装的方法可以对传入的参数做检查，避免传入无效参数：

```python
class Student(object):
    def get_name(self):
        return self.__name

    def get_score(self):
        return self.__score

    def set_score(self, score):
        if 0 <= score <= 100:
            self.__score = score
        else:
            raise ValueError('bad score')
```

> **注意**：`__name` 不代表一定不能从外部访问——Python 解释器对外把 `__name` 改为了 `_Student__name`，所以仍然可以通过 `_Student__name` 访问到 `__name` 变量。只是强烈不建议这么做。

## 继承和多态

在面向对象程序设计中，定义一个 class 可以从现有的 class **继承**：新的 class 称为**子类**，被继承的 class 称为**父类**。

这里有一个 Animal 的 class：

```python
class Animal(object):
    def run(self):
        print('Animal is running...')
```

编写 Dog 和 Cat 时，就可以直接从 Animal 类继承：

```python
class Dog(Animal):
    pass

class Cat(Animal):
    pass
```

即使两个子类什么也没有，也会默认拥有父类的 run() 方法：

```python
>>> dog = Dog()
>>> dog.run()
Animal is running...
```

也可以对子类**增加新方法**、**修改原有方法**：

```python
class Dog(Animal):
    def run(self):
        print('Dog is running...')

    def eat(self):
        print('Eating meat...')
```

当子类和父类存在**相同的方法**（如 `run()`）时，**子类方法会覆盖父类的方法**（override）。

当我们定义一个 class 的时候，实际上定义了一个数据类型。通过 `isinstance()` 可以发现：

```python
>>> c = Dog()
>>> isinstance(c, Dog)
True
>>> isinstance(c, Animal)
True
```

Dog 类的实例不仅是 Dog 类型，同时还是 Dog 的父类 Animal 类型——这个就叫做**多态**。

**多态的好处**：当我们需要传入 Dog、Cat、Tortoise 等类型时，只需要接受它们共同的父类 Animal 类型即可，之后按照 Animal 类型操作。由于 Animal 有 run() 方法，因此传入的任意类型都可以调用 run() 方法，并且**调用的是实际类型的 run()**。

对于一个变量，我们只需要知道它是 `Animal` 类型，无需确切知道它的子类型，就可以放心地调用 `run()` 方法，而具体调用的 `run()` 是作用在 `Animal`、`Dog`、`Cat` 还是 `Tortoise` 对象上，由**运行时该对象的确切类型**决定——这就是多态真正的威力：**调用方只管调用，不管细节**。当我们新增一种 `Animal` 的子类时，只要确保 `run()` 方法编写正确，不用管原来的代码如何调用。这就是著名的**"开闭"原则**：

- **对扩展开放**：允许新增 `Animal` 子类；
- **对修改封闭**：不需要修改依赖 `Animal` 类型的 `run_twice()` 等函数。

## 静态语言 VS 动态语言

对于 Java 那种**静态语言**，如果需要传入 `Animal` 类型，则传入的对象必须是 `Animal` 类型或者它的子类，否则将无法调用 `run()` 方法。

但 **Python 是动态语言**，不一定需要传入 Animal 类型，**只要传入一个"有 run() 方法的对象"就可以**。

### 小结

- 继承可以把父类的所有功能都直接拿过来，这样就不必从零做起，子类只需要**新增自己特有的方法**，也可以把父类不适合的方法**覆盖重写**。
- 动态语言的**鸭子类型**特点决定了继承不像静态语言那样是必须的。

## 获取对象信息

当我们拿到一个对象的引用时，如何知道这个对象是什么类型、有哪些方法？

### type()：基本类型与函数

`type()` 可以判断一个对象的类型，基本类型、函数和类都可以依靠它判断：

```python
>>> type(123)
<class 'int'>
>>> type('str')
<class 'str'>
>>> type(None)
<class 'NoneType'>
```

```python
>>> type(abs)
<class 'builtin_function_or_method'>
>>> type(a)
<class '__main__.Animal'>
```

`type()` 会返回对应的 class 类型，所以如果要在 if 语句中判断，可以比较两个变量的 type 类型是否相同：

```python
>>> type(123) == type(456)
True
>>> type(123) == int
True
>>> type('abc') == type('123')
True
>>> type('abc') == str
True
>>> type('abc') == type(123)
False
```

判断基本数据类型可以直接用 `int`、`str` 等；要判断一个对象是否是**函数**，需要用到 `types` 模块：

```python
import types

def fn():
    pass

type(fn) == types.FunctionType          # True  普通用户定义的函数
type(abs) == types.BuiltinFunctionType  # True  内置函数（如 abs、print）
type(lambda x: x) == types.LambdaType   # True  lambda 表达式（LambdaType 是 FunctionType 的别名）
type((x for x in range(10))) == types.GeneratorType  # True  生成器对象
```

### isinstance()：判断类型

使用 `isinstance()` 可以判断类（对于继承关系也能正确判断），当然也可以判断基本类型：

```python
>>> isinstance('a', str)
True
>>> isinstance(123, int)
True
>>> isinstance(b'a', bytes)
True
```

还可以判断一个变量**是否是某些类型中的一种**（传入一个类型元组）：

```python
import types

def is_function(obj):
    return isinstance(obj, (types.FunctionType, types.BuiltinFunctionType, types.LambdaType))

is_function(fn)          # True
is_function(abs)         # True
is_function(lambda x: x) # True
```

### dir()：获得所有属性和方法

`dir()` 可以获得一个对象的**所有属性和方法**，返回一个包含字符串的 list：

```python
>>> dir('ABC')
['__add__', '__class__', ..., '__subclasshook__', 'capitalize', 'casefold', ..., 'zfill']
```

类似 `__xxx__` 的属性方法都是有特殊作用的。比如 `__len__` 可以返回长度——实际上使用 `len()` 函数**就是去调用对象的 `__len__`**，所以下面的代码是等价的：

```python
>>> len('ABC')
3
>>> 'ABC'.__len__()
3
```

自己写的类如果也想用 `len()`，就要自己写一个 `__len__` 方法。

### getattr() / setattr() / hasattr()

Python 内置的 `getattr()`、`setattr()` 以及 `hasattr()` 可以直接操作一个对象的状态：

```python
class Person:
    name = "Alice"
    age = 30

p = Person()
print(getattr(p, "name"))          # 输出: Alice
print(getattr(p, "age"))           # 输出: 30
print(getattr(p, "gender", "N/A")) # 输出: N/A（属性不存在，返回默认值）
print(getattr(p, "gender"))        # 会抛出 AttributeError

setattr(p, "age", 25)      # 创建新属性 age
print(p.age)               # 输出: 25
setattr(p, "name", "Bob")  # 修改已有属性 name
print(p.name)              # 输出: Bob

print(hasattr(p, "name"))  # True
print(hasattr(p, "age"))   # True
```

| 函数 | 作用 | 异常处理 |
| --- | --- | --- |
| `getattr` | 获取属性值 | 可提供默认值，否则抛异常 |
| `setattr` | 设置或创建属性 | 无异常（除非对象不允许） |
| `hasattr` | 检查属性是否存在 | 返回布尔值，不抛异常 |

## 实例属性和类属性

Python 是动态语言，根据创建的实例可以**任意绑定属性**。给实例绑定属性的方法是通过**实例变量**或 `self` 变量。

还可以给**类本身**绑定一个属性，叫做**类属性**，归 Student 类所有：

```python
class Student(object):
    name = 'Student'
```

类的所有实例都能访问到类属性，但**实例属性的优先级比类属性高**：

```python
>>> class Student(object):
...     name = 'Student'
...
>>> s = Student()       # 创建实例 s
>>> print(s.name)       # 实例没有 name 属性，继续查找 class 的 name 属性
Student
>>> print(Student.name) # 打印类的 name 属性
Student
>>> s.name = 'Michael'  # 给实例绑定 name 属性
>>> print(s.name)       # 实例属性优先级比类属性高，屏蔽掉类的 name 属性
Michael
>>> print(Student.name) # 类属性并未消失，用 Student.name 仍然可以访问
Student
>>> del s.name          # 删除实例的 name 属性
>>> print(s.name)       # 实例的 name 属性没找到，类的 name 属性就显示出来了
Student
```
