# Python 函数

## 函数的调用

要调用一个函数，需要知道函数的**名称**和**参数**。例如求绝对值的 `abs` 函数，可以直接从 Python 官方文档查看，也可以通过 `help(abs)` 命令查看信息：

```python
>>> help(abs)
Help on built-in function abs in module builtins:    # abs 是内置函数，位于 builtins 模块，无需导入

abs(x, /)                                             # 只有一个参数，而且是仅限位置参数
    Return the absolute value of the argument.        # 功能说明
```

调用函数时，如果传入的参数**数量不对**或**参数类型不被接受**，会报 `TypeError` 错误：

```python
>>> abs(1, 2)
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
TypeError: abs() takes exactly one argument (2 given)
```

```python
>>> abs('a')
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
TypeError: bad operand type for abs(): 'str'
```

本质上，**函数名就是一个指向函数对象的引用**，所以可以把函数名赋给一个变量，再通过变量调用该函数：

```python
>>> a = abs      # 变量 a 指向 abs 函数
>>> a(-1)        # 通过 a 调用 abs 函数
1
```

## 定义函数

使用 `def` 语句定义函数，依次写出**函数名、括号、参数、冒号**，然后在缩进块中编写函数体，用 `return` 语句返回结果：

```python
def my_abs(x):
    if x >= 0:
        return x
    else:
        return -x

print(my_abs(-99))
```

函数内部的语句一旦执行到 `return`，函数就执行完毕并返回结果。如果没有 `return` 语句，函数执行完毕后也会返回，只是结果为 `None`。

把函数定义保存为 `XXX.py` 文件，就可以在当前目录启动 Python 解释器，用 `from XXX import 函数名` 导入该函数（其中 `XXX` 是文件名）。

## 空函数

如果想定义一个什么都不做的空函数，可以用 `pass` 语句：

```python
def nop():
    pass
```

`pass` 常用于占位符：函数还没写好时，先放一个 `pass`，让代码先跑起来。

## 参数检查

调用函数时，如果**参数个数**不对，Python 解释器会自动检查并抛出 `TypeError`；但如果**参数类型**不对，解释器不会检查——除非我们手动加入类型检查：

```python
def my_abs(x):
    if not isinstance(x, (int, float)):
        raise TypeError('bad operand type')
    if x >= 0:
        return x
    else:
        return -x
```

加入参数检查后，函数就能在传入错误类型时正常抛出异常。

## 返回多个值

函数可以返回多个值，以下是一个移动函数：

```python
import math   # 导入 math 包，后续才可以使用 sin、cos 等函数

def move(x, y, step, angle=0):
    nx = x + step * math.cos(angle)
    ny = y - step * math.sin(angle)
    return nx, ny
```

虽然我们看到"返回了两个值"，但实际上函数返回的是一个**元组**。

## 位置参数

除了正常定义的**必选参数**外，Python 还支持**默认参数、可变参数、关键字参数和命名关键字参数**，这 5 种参数可以组合使用。

先写一个计算 x 的平方的函数：

```python
def power(x):
    return x * x
```

调用 `power` 函数时，必须传入**有且仅有一个**参数 x。如果要计算 x 的三次方，可以把 `power(x)` 修改为 `power(x, n)`，用来计算 x 的 n 次方：

```python
def power(x, n):
    s = 1
    while n > 0:
        n = n - 1
        s = s * x
    return s
```

`power(x, n)` 的两个参数 x、n 都是**位置参数**——调用时必须按顺序传入完整的参数，不能多也不能少。

## 默认参数

新的 `power(x, n)` 定义没问题，但**旧的调用代码就失效了**，因为函数多了一个参数。既然经常计算 x 的平方，就可以把第二个参数 n 的默认值设定为 2：

```python
def power(x, n=2):
    s = 1
    while n > 0:
        n = n - 1
        s = s * x
    return s
```

这样调用 `power(5)` 就相当于 `power(5, 2)`。默认参数可以**简化函数的调用**，不过设置默认参数时要注意：

1. **必选参数在前，默认参数在后**，否则 Python 解释器会报语法错误。
2. 当函数有多个参数时，把**变化大**的参数放前面，**变化小**的参数放后面（作为默认参数），这样调用时最常用的情况只需传少量参数。

### 默认参数必须指向不变对象！

默认参数虽然很有用，但必须谨记一点：**默认参数必须指向不变对象**。看这个函数：

```python
def add_end(L=[]):
    L.append('END')
    return L
```

看上去不错，实际调用却有问题——如果使用默认参数调用：

```python
>>> add_end()
['END']
>>> add_end()
['END', 'END']
>>> add_end()
['END', 'END', 'END']
```

原因：**函数的默认参数值只在函数定义时创建一次**。之后调用 `add_end()` 时，如果没有传入新的参数，L 就会引用同一个默认列表对象，`'END'` 被不断追加进去。

解决办法是使用 `None` 作为默认值：

```python
def add_end(L=None):
    if L is None:
        L = []
    L.append('END')
    return L
```

这样每次调用都会新建一个列表，问题就解决了。

## 可变参数

**可变参数**就是传入的参数个数是可变的，可以是 0 个到任意个。例如要计算 `a 的平方 + b 的平方 + c 的平方 + ...`：

由于参数个数不确定，首先想到把参数作为一个列表或元组传进来：

```python
def calc(numbers):
    sum = 0
    for n in numbers:
        sum = sum + n * n
    return sum
```

虽然能解决问题，但每次调用都要先构造一个 list。更优的方法是把函数参数改为**可变参数**：

```python
def calc(*numbers):
    sum = 0
    for n in numbers:
        sum = sum + n * n
    return sum
```

定义可变参数只需在参数名前加一个 `*`，函数内部会自动组装为一个 **tuple**：

```python
>>> calc(1, 2)
5
>>> calc(1, 2, 3)
14
>>> calc()
0
```

如果已经有一个 list 或 tuple，Python 允许使用 `*nums` 表示把 `nums` 的所有元素作为可变参数传进去：

```python
>>> nums = [1, 2, 3]
>>> calc(*nums)
14
```

> `calc(*nums)` 等价于 `calc(nums[0], nums[1], nums[2])`：`*nums` 表示把 list/tuple 的所有元素"拆开"逐个传入。

## 关键字参数

**可变参数**允许传入 0 个或任意个参数，调用时自动组装为一个 tuple；而**关键字参数**允许传入 0 个或任意个**含参数名**的参数，这些关键字参数在函数内部自动组装为一个 **dict**：

```python
def person(name, age, **kw):
    print('name:', name, 'age:', age, 'other:', kw)
```

`person` 函数除了必选参数 name 和 age 外，还接受关键字参数 kw。既可以只传入必选参数：

```python
>>> person('Michael', 30)
name: Michael age: 30 other: {}
```

也可以传入任意个数的关键字参数：

```python
>>> person('Bob', 35, city='Beijing')
name: Bob age: 35 other: {'city': 'Beijing'}
>>> person('Adam', 45, gender='M', job='Engineer')
name: Adam age: 45 other: {'gender': 'M', 'job': 'Engineer'}
```

> **关键字参数有什么用？**它可以扩展函数的功能。比如做用户注册时，除了用户名和年龄必填外，其他信息都是可选项——用关键字参数就能灵活接收，不用在函数定义里一一列出所有参数。

## 命名关键字参数

调用者可以传入任意不受限制的关键字参数，但有时我们希望**限制关键字参数的名字**，只接收指定的参数。可以先在函数内部检查 kw：

```python
def person(name, age, **kw):
    if 'city' in kw:
        # 有 city 参数
        pass
    if 'job' in kw:
        # 有 job 参数
        pass
    print('name:', name, 'age:', age, 'other:', kw)
```

（这里的 `pass` 只是占位符，不会起到任何作用。）

要直接限制关键字参数的名字，可以用**命名关键字参数**。例如只接收 `city` 和 `job` 作为关键字参数，定义时用特殊分隔符 `*` 把位置参数和命名关键字参数隔开：

```python
def person(name, age, *, city, job):
    print(name, age, city, job)
```

调用方式：

```python
>>> person('Jack', 24, city='Beijing', job='Engineer')
Jack 24 Beijing Engineer
```

如果函数定义中已经有一个可变参数，后面跟着的命名关键字参数就**不再需要特殊分隔符 `*`**：

```python
def person(name, age, *args, city, job):
    print(name, age, args, city, job)
```

**命名关键字参数必须传入参数名**，这和位置参数不同；如果没有传入参数名，调用将报错：

```python
>>> person('Jack', 24, 'Beijing', 'Engineer')
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
TypeError: person() takes 2 positional arguments but 4 were given
```

## 参数组合

在 Python 中定义函数，可以用必选参数、默认参数、可变参数、关键字参数和命名关键字参数，这 5 种参数**都可以组合使用**。但是组合使用有顺序要求：

> 必选参数 → 默认参数 → 可变参数 → 命名关键字参数 → 关键字参数

```python
def f1(a, b, c=0, *args, **kw):
    print('a =', a, 'b =', b, 'c =', c, 'args =', args, 'kw =', kw)

def f2(a, b, c=0, *, d, **kw):
    print('a =', a, 'b =', b, 'c =', c, 'd =', d, 'kw =', kw)
```

在函数调用的时候，Python 解释器自动按照**参数位置和参数名**把对应的参数传进去：

```python
>>> f1(1, 2)
a = 1 b = 2 c = 0 args = () kw = {}
>>> f1(1, 2, c=3)
a = 1 b = 2 c = 3 args = () kw = {}
>>> f1(1, 2, 3, 'a', 'b')
a = 1 b = 2 c = 3 args = ('a', 'b') kw = {}
>>> f1(1, 2, 3, 'a', 'b', x=99)
a = 1 b = 2 c = 3 args = ('a', 'b') kw = {'x': 99}
>>> f2(1, 2, d=99, ext=None)
a = 1 b = 2 c = 0 d = 99 kw = {'ext': None}
```

通过 tuple 和 dict，也可以调用上述函数：

```python
>>> args = (1, 2, 3, 4)
>>> kw = {'d': 99, 'x': '#'}
>>> f1(*args, **kw)
a = 1 b = 2 c = 3 args = (4,) kw = {'d': 99, 'x': '#'}
>>> args = (1, 2, 3)
>>> kw = {'d': 88, 'x': '#'}
>>> f2(*args, **kw)
a = 1 b = 2 c = 3 d = 88 kw = {'x': '#'}
```

所以，对于任意函数，都可以通过类似 `func(*args, **kw)` 的形式调用它，无论它的参数是如何定义的。

## 五种参数小结

| 参数类型 | 定义写法 | 调用示例 | 函数内部 |
| --- | --- | --- | --- |
| 位置参数 | `def f(a, b)` | `f(1, 2)` | 按位置顺序取值 |
| 默认参数 | `def f(a, b=2)` | `f(1)` | 缺省时使用默认值 |
| 可变参数 | `def f(*args)` | `f(1, 2, 3)` | 自动组装为 tuple |
| 关键字参数 | `def f(**kw)` | `f(x=1, y=2)` | 自动组装为 dict |
| 命名关键字参数 | `def f(*, city)` | `f(city='Beijing')` | 限定名字的关键字 |

> **记忆要点**：`*` 收集多余的位置参数为 tuple，`**` 收集多余的关键字参数为 dict；`*` 单独出现时，后面的参数是命名关键字参数。

## 什么是递归函数

在函数内部，可以调用其他函数。如果一个函数**在内部调用自身本身**，这个函数就是**递归函数**。

以计算阶乘 `n! = 1 × 2 × 3 × ... × n` 为例，用函数 `fact(n)` 表示，可以看出：

> `fact(n) = n! = (n-1)! × n = fact(n-1) × n`

所以 `fact(n)` 可以写成：

```python
def fact(n):
    if n == 1:
        return 1
    return n * fact(n - 1)
```

递归函数的**优点是定义简单，逻辑清晰**。理论上，所有的递归函数都可以写成循环的方式，但循环的逻辑不如递归清晰。

## 递归的两个要素

任何递归函数都只有两个零件：

```python
def 递归函数(问题):
    if 问题小到不用再拆:        # ① 出口（终止条件）——最重要
        return 直接答案
    else:                      # ② 递归式子——把问题变小
        return 用更小的同款问题算出答案
```

1. **终止条件（出口）**：问题小到不用再拆时直接返回，如上例的 `if n == 1: return 1`。**缺少出口的递归会无限调用下去，最终栈溢出。**
2. **递归式子**：把大问题拆成更小的同款问题，如上例的 `fact(n-1) × n`。

## 递归的执行过程："递"与"归"

> **理解技巧**：递归 = "递" + "归"。"递"是一层层往下调用（每层都在等待下一层的结果），"归"是触底之后结果一层层返回来。可以自己运行下面的小实验观察打印顺序：

```python
def countdown(n):
    if n == 0:
        print('BOOM!')
    else:
        print('倒计时:', n)
        countdown(n - 1)      # 递：调用自己
    print('返回本层:', n)      # 归：触底后一层层返回

countdown(3)
# 倒计时: 3 → 倒计时: 2 → 倒计时: 1 → BOOM! → 返回本层: 0 → 返回本层: 1 → 返回本层: 2 → 返回本层: 3
```

把 `fact(5)` 的计算过程展开，可以清楚看到"先递后归"：

```python
===> fact(5)
===> 5 * fact(4)
===> 5 * (4 * fact(3))
===> 5 * (4 * (3 * fact(2)))
===> 5 * (4 * (3 * (2 * fact(1))))
===> 5 * (4 * (3 * (2 * 1)))      # 触底，开始"归"
===> 5 * (4 * (3 * 2))
===> 5 * (4 * 6)
===> 5 * 24
===> 120
```

> 写递归跟做数学归纳法一样：**假设"更小的子问题已经能正确算出来"**，只要出口正确 + 拆法正确，整个函数就正确。人肉跟踪每一层是调试时才做的事。真想看过程，就去 [Python Tutor](https://pythontutor.com/) 把代码粘进去，它会一步步画栈帧的进出，看两遍就通了。

## 递归调用与栈

使用递归函数需要注意防止**栈溢出**。

计算机中，函数调用是通过**栈（stack）**这种数据结构实现的：每进入一个函数调用，栈就加一层**栈帧**；函数返回，栈就减一层栈帧。每次递归深入一层，就多一层栈帧被"挂起"等待，所以递归调用的次数过多，会导致栈溢出：

```python
>>> fact(1000)
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
  File "<stdin>", line 4, in fact
  ...
  File "<stdin>", line 4, in fact
RuntimeError: maximum recursion depth exceeded in comparison
```

## 尾递归

解决递归调用栈溢出的方法是使用**尾递归**优化。事实上尾递归和循环的效果是一样的，把循环看成一种特殊的尾递归函数也可以。

**尾递归**是指：在函数返回的时候调用自身本身，并且 return 语句**不能包含表达式**。这样，编译器或解释器就可以把尾递归做优化，使递归无论调用多少次，都**只占用一个栈帧**，不会出现栈溢出。

上面的 `fact(n)` 由于 `return n * fact(n - 1)` 引入了乘法表达式，所以不是尾递归。要改成尾递归，需要把每一步的乘积传入递归函数：

```python
def fact(n):
    return fact_iter(n, 1)

def fact_iter(num, product):
    if num == 1:
        return product
    return fact_iter(num - 1, num * product)
```

`return fact_iter(num - 1, num * product)` 仅返回递归函数本身：`num - 1` 和 `num * product` 在函数调用前就已经被计算好了，返回时没有多余表达式，符合尾递归定义。

> **注意**：Python 标准的解释器**并没有**针对尾递归做优化，任何递归函数都存在栈溢出的问题。尾递归更多是理解"优化思路"；实际写 Python 时，递归太深仍会爆栈，此时应改用循环。
