# Python 面向对象高级编程

本章介绍 Python 面向对象的高级特性：动态绑定属性和方法、`__slots__`、`@property`、多重继承与 Mixin、枚举类，以及动态创建类的 `type()` 和元类（metaclass）。

## 动态给实例和类绑定属性、方法

正常情况下，定义一个类并创建实例后，可以给实例**绑定任何属性和方法**：

```python
class Student(object):
    pass

>>> s = Student()
>>> s.name = 'Michael'          # 动态给实例绑定一个属性
>>> print(s.name)
Michael

>>> def set_age(self, age):     # 定义一个函数作为实例方法
...     self.age = age
...
>>> from types import MethodType
>>> s.set_age = MethodType(set_age, s)   # 给实例绑定一个方法
>>> s.set_age(25)
>>> s.age
25
```

`MethodType(set_age, s)` 把之前定义的 `set_age` 和实例 `s` **打包**在一起，生成一个新的**绑定方法对象**。经过 `MethodType` 绑定后，调用时 `s` 会**强制占据**原函数的第一个参数位，括号里写的参数只能从第二个位置开始排。

这样绑定的方法**只有这一个实例**能调用。如果想让所有实例都能用，可以给 **class 绑定方法**：

```python
>>> def set_score(self, score):
...     self.score = score
...
>>> Student.set_score = set_score
```

给 class 绑定方法时**不需要** `MethodType()`，因为 Python 的描述符协议会在类上起作用。

## `__slots__`：限制实例能添加的属性

Python 允许在定义 class 的时候定义一个特殊的 `__slots__` 变量，来**限制该 class 实例能添加的属性**：

```python
class Student(object):
    __slots__ = ('name', 'age')    # 用 tuple 定义允许绑定的属性名称
```

之后绑定不允许的属性就会报错：

```python
>>> s = Student()          # 创建新的实例
>>> s.name = 'Michael'     # 绑定属性 name
>>> s.age = 25             # 绑定属性 age
>>> s.score = 99           # 绑定属性 score
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
AttributeError: 'Student' object has no attribute 'score'
```

> **PS：`__slots__` 与继承**
> - 父类 `__slots__` 中声明的属性仍然会存在于子类实例上，比如 `name` 仍可作为 slot 属性使用；
> - 但子类如果**没有**定义自己的 `__slots__`，子类会自动获得 `__dict__`，因此不再受父类 `__slots__` 的限制，可以随意添加新属性；
> - 如果子类**也**定义了 `__slots__`，且父类本身也因 `__slots__` 而没有 `__dict__`，那么子类实例通常也没有 `__dict__`，允许定义的属性是"父类 `__slots__` + 子类 `__slots__`"的**并集**；
> - 例外：子类 `__slots__` 中显式写了 `'__dict__'`，那子类实例仍然可以任意添加属性。

## `@property`：把方法变成属性调用

之前提到过，尽量在 class 内部定义 set/get 方法来设置和获取参数，在方法里可以检查参数：

```python
class Student(object):
    def get_score(self):
        return self._score

    def set_score(self, value):
        if not isinstance(value, int):
            raise ValueError('score must be an integer!')
        if value < 0 or value > 100:
            raise ValueError('score must between 0 ~ 100!')
        self._score = value
```

但这样调用又过于复杂。装饰器可以给函数动态加上功能，所以用 `@property` 装饰器**把一个方法变成属性调用**：

```python
class Student(object):
    @property
    def score(self):
        return self._score

    @score.setter
    def score(self, value):
        if not isinstance(value, int):
            raise ValueError('score must be an integer!')
        if value < 0 or value > 100:
            raise ValueError('score must between 0 ~ 100!')
        self._score = value
```

- 想把一个 **getter 方法**变成属性，只需加上 `@property`；
- `@property` 本身会创建另一个装饰器 `@score.setter`，负责把 **setter 方法**变成属性赋值；
- 可以**只定义 getter、不定义 setter**，让属性变成只读；
- 注意：属性的方法名**不要和实例变量重名**。

> **PS：`raise` 语句**用于抛出异常，最常见的用法就是 `raise 异常类('描述信息')`；也可以在 except 代码块中把当前捕获到的异常重新抛出。

## 多重继承与 Mixin

一个子类可以同时继承**多个父类**，并且获得多个父类的所有功能：

```python
class MyTCPServer(TCPServer, ForkingMixIn):
    pass
```

**Mixin** 的设计要点：

- 设计类的继承关系时，一般是**一条线单一继承**；如果需要添加额外功能，通过**多重继承**实现；
- 为其他类提供可复用功能的类叫做 **Mixin**，一般以 `MixIn` 结尾；
- Mixin 的目的是给一个类**增加功能**，所以它的功能单一、**不包含状态**、**不单独使用**；
- 比如 TCPServer 和 UDPServer 这两类网络服务，Python 也自带了多进程、多线程模型 `ForkingMixIn` 和 `ThreadingMixIn`，可以很方便地快速构造出所需的子类。

## 枚举类（Enum）

定义常量可以用大写变量（通过整数来定义），但实际上它还是变量，并且类型是 `int`。最好直接为这种枚举类型定义一个 class 类型，每个常量都是 class 的唯一实例。Python 提供了 `Enum` 类来实现这个功能：

```python
from enum import Enum

Month = Enum('Month', ('Jan', 'Feb', 'Mar', 'Apr', 'May', 'Jun',
                       'Jul', 'Aug', 'Sep', 'Oct', 'Nov', 'Dec'))
```

遍历所有成员：

```python
for name, member in Month.__members__.items():
    print(name, '=>', member, ',', member.value)
```

- `__members__` 是枚举类的**特殊属性**，返回一个 dict，包含枚举类中的所有映射关系；
- `.items()` 是字典的方法，返回键值对列表，每个元素都是 `(key, value)` 元组；
- `value` 属性是自动赋给成员的 **int 变量**，默认**从 1 开始**计数。

如果需要更精准地控制枚举类型，可以从 `Enum` 派生出自定义类：

```python
from enum import Enum, unique

@unique
class Weekday(Enum):
    Sun = 0    # Sun 的 value 被设定为 0
    Mon = 1
    Tue = 2
    Wed = 3
    Thu = 4
    Fri = 5
    Sat = 6
```

`@unique` 装饰器检查并保证**没有重复值**。

## type()：动态创建类

动态语言中，函数和类的定义是**运行时动态创建**的。

`type()` 函数可以查看一个变量的类型；此外，它还有**创建新类型**的功能——可以直接用 `type()` 创建出 Hello 类，不需要 `class Hello(object)` 的定义：

```python
>>> def fn(self, name='world'):    # 先定义函数
...     print('Hello, %s.' % name)
...
>>> Hello = type('Hello', (object,), dict(hello=fn))   # 创建 Hello class
>>> h = Hello()
>>> h.hello()
Hello, world.
>>> print(type(Hello))
<class 'type'>
>>> print(type(h))
<class '__main__.Hello'>
```

创建 class 对象时，`type()` 函数依次传入三个参数：

1. **class 的名称**；
2. **继承的父类集合**（写成 `(object,)`，后面的逗号是因为这是一个元组）；
3. **class 的方法名称与函数的绑定**（用 dict 传入）。

通过 `type()` 函数创建的类和直接写 `class` 是**完全等价**的——动态语言本身支持运行期动态创建类。

## metaclass（元类）

**元类继承自 `type`**，元类的作用是**控制"类"的创建过程**，就像类是控制"实例"创建的模板一样：

```python
class ListMetaclass(type):
    def __new__(cls, name, bases, attrs):
        attrs['add'] = lambda self, value: self.append(value)
        return type.__new__(cls, name, bases, attrs)
```

当使用该元类创建一个新类时，会调用 `__new__` 方法，参数含义分别为：

- `cls`：当前元类；
- `name`：要创建的类的名字；
- `bases`：要创建的类的基类元组；
- `attrs`：一个字典，包含要创建的类的所有属性和方法。

上面向 `attrs` 字典中添加了一个名为 `add` 的方法，它接受 `self` 和 `value` 两个参数（`self` 是类的实例对象，`value` 是要添加的值）。最后 `return type.__new__(cls, name, bases, attrs)` 调用父类 `type` 的 `__new__` 方法，用修改后的 `attrs` 来创建类。

要使用元类，在定义类时指定 `metaclass`：

```python
class MyList(list, metaclass=ListMetaclass):
    pass
```

元类最常用于 **ORM 框架**：ORM 是对象-关系映射，把关系数据库的一行映射为一个对象、一个类对应一个表。编写 ORM 框架时，所有类都只能**动态定义**，因为只有使用者才能根据表的结构定义出对应的类。
