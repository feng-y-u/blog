# Python 函数

## 函数的调用

要调用一个函数，需要知道函数的**名称**和**参数**。例如求绝对值的 `abs` 函数，可以直接从 Python 官方文档查看，也可以通过 `help(abs)` 命令查看信息：

```python
>>> help(abs)
Help on built-in function abs in module builtins:    # abs 是内置函数，位于 builtins 模块，无需导入

abs(x, /)                                             # 只有一个参数，而且是仅限位置参数
    Return the absolute value of the argument.        # 功能说明
```

调用函数时，如果传入的参数**数量不对**或**参数类型不被接受**，会报 `TypeError` 错误：

```python
>>> abs(1, 2)
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
TypeError: abs() takes exactly one argument (2 given)
```

```python
>>> abs('a')
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
TypeError: bad operand type for abs(): 'str'
```

本质上，**函数名就是一个指向函数对象的引用**，所以可以把函数名赋给一个变量，再通过变量调用该函数：

```python
>>> a = abs      # 变量 a 指向 abs 函数
>>> a(-1)        # 通过 a 调用 abs 函数
1
```

## 定义函数

使用 `def` 语句定义函数，依次写出**函数名、括号、参数、冒号**，然后在缩进块中编写函数体，用 `return` 语句返回结果：

```python
def my_abs(x):
    if x >= 0:
        return x
    else:
        return -x

print(my_abs(-99))
```

函数内部的语句一旦执行到 `return`，函数就执行完毕并返回结果。如果没有 `return` 语句，函数执行完毕后也会返回，只是结果为 `None`。

把函数定义保存为 `XXX.py` 文件，就可以在当前目录启动 Python 解释器，用 `from XXX import 函数名` 导入该函数（其中 `XXX` 是文件名）。

## 空函数

如果想定义一个什么都不做的空函数，可以用 `pass` 语句：

```python
def nop():
    pass
```

`pass` 常用于占位符：函数还没写好时，先放一个 `pass`，让代码先跑起来。

## 参数检查

调用函数时，如果**参数个数**不对，Python 解释器会自动检查并抛出 `TypeError`；但如果**参数类型**不对，解释器不会检查——除非我们手动加入类型检查：

```python
def my_abs(x):
    if not isinstance(x, (int, float)):
        raise TypeError('bad operand type')
    if x >= 0:
        return x
    else:
        return -x
```

加入参数检查后，函数就能在传入错误类型时正常抛出异常。

## 返回多个值

函数可以返回多个值，以下是一个移动函数：

```python
import math   # 导入 math 包，后续才可以使用 sin、cos 等函数

def move(x, y, step, angle=0):
    nx = x + step * math.cos(angle)
    ny = y - step * math.sin(angle)
    return nx, ny
```

虽然我们看到"返回了两个值"，但实际上函数返回的是一个**元组**。
