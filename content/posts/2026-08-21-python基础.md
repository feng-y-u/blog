# Python 基础

## 数据类型和变量

### 数字

- Python 允许在数字之间用下划线分割，`10000` 和 `10_000` 一样；十六进制同样支持，`0xa1b2c3` 与 `0xa1_b2c3` 相同。

### 字符串

- 如果字符串内部和外部同时出现 `'` 和 `"`，需要使用转义字符 `\`。
- 使用 `r'...'` 表示内部字符串默认**不转义**。
- 如果字符串内部有很多换行，使用 `'''...'''` 表示多行内容；也有与 `r'...'` 相同形式的 `r'''...'''`。

### 布尔值

- 布尔值只有 `True` 和 `False`（注意大小写），使用 `and`、`or`、`not` 运算。

### 空值

- Python 里的空值用 `None` 表示。

## 变量

- 变量名必须是字母、数字、下划线的组合，且**不能以数字开头**。
- Python 是**动态语言**，可以把任意数据类型赋值给一个变量，同一个变量可以被反复赋值为不同数据类型的数据。

## 常量

- Python 中通常使用**全大写变量名**表示常量。

> **补充**：Python 的整数没有大小限制，而某些语言的整数根据存储长度有限制（如 Java 的 32 位整数范围是 `-2147483648` ~ `2147483647`）；Python 的浮点数也没有大小限制，但超出一定范围会直接表示为 `inf`（无限大）。

## 字符串和编码

### 内存中的编码

- 在计算机内存中统一使用 **Unicode** 编码；保存到硬盘或传输时转换为 **UTF-8** 编码。
- Python 3 的字符串以 Unicode 编码，因此**支持多语言**。
- 对单个字符：`ord()` 获取字符的整数表示，`chr()` 把编码转换为对应的字符：

```python
>>> ord('A')
65
>>> ord('中')
20013
>>> chr(66)
'B'
>>> chr(25991)
'文'
```

### str 与 bytes

- 字符串类型是 `str`，在内存中以 Unicode 表示，一个字符对应若干个字节；保存或传输时要把 `str` 变为以字节为单位的 `bytes`。
- `bytes` 类型用带 `b` 前缀的引号表示：`x = b'ABC'`。
- `str.encode()` 编码为指定编码的 `bytes`：

```python
>>> 'ABC'.encode('ascii')
b'ABC'
>>> '中文'.encode('utf-8')
b'\xe4\xb8\xad\xe6\x96\x87'
```

- 用 `bytes.decode()` 把 `bytes` 变回 `str`：

```python
>>> b'ABC'.decode('ascii')
'ABC'
>>> b'\xe4\xb8\xad\xe6\x96\x87'.decode('utf-8')
'中文'
```

### len() 计算长度

- `len()` 可计算 `str` 包含多少个**字符**，也可计算 `bytes` 有多少个**字节**：

```python
>>> len('ABC')
3
>>> len('中文')
2
>>> len(b'ABC')
3
>>> len(b'\xe4\xb8\xad\xe6\x96\x87')
6
>>> len('中文'.encode('utf-8'))
6
```

可以看到：一个中文字符经 UTF-8 编码后占用 **3 字节**，一个英文字符只占用 **1 字节**。

> 操作字符串时，为避免乱码，应始终坚持使用 **UTF-8** 编码进行 `str` 与 `bytes` 的转换。

### 保存源代码

Python 源代码本身也是文本文件，当代码含中文时，保存时必须指定为 UTF-8 编码。为了让 Python 解释器按 UTF-8 读取源码，通常在文件开头写这两行：

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-
```

- 第一行告诉 Linux/OS X 系统这是一个 Python 可执行程序（Windows 会忽略）。
- 第二行告诉 Python 解释器按 UTF-8 编码读取源代码。

## 格式化

### 传统 % 格式化

与 C 语言一样，用 `%` 实现：

```python
>>> 'Hello, %s' % 'world'
'Hello, world'
>>> 'Hi, %s, you have $%d.' % ('Michael', 1000000)
'Hi, Michael, you have $1000000.'
```

其中 `%d` 替换整数、`%f` 替换浮点数、`%s` 替换字符串、`%x` 替换十六进制整数。

- 格式化整数和浮点数还可以指定**是否补 0** 以及**整数与小数的位数**：

```python
>>> print('%2d-%02d' % (3, 1))
 3-01
```

`%2d`：宽度 2，在 `3` 前面用空格填充一格；`%02d`：宽度 2、补 0，在 `1` 前面用 0 填充一格。

```python
>>> print('%.2f' % 3.1415926)
3.14
```

`%.2f`：保留两位小数。

- 如果想把 `%` 作为字符串的一部分输出，用 `%%` 转义：

```python
>>> 'growth rate: %d %%' % 7
'growth rate: 7 %'
```

### format() 方法

字符串的 `format()` 方法用传入的参数依次替换占位符 `{0}`、`{1}`…

```python
>>> 'Hello, {0}, 成绩提升了 {1:.1f}%'.format('小明', 17.125)
'Hello, 小明, 成绩提升了 17.1%'
```

因为占位符是 `{}`，所以字面要输出 `{` 或 `}` 时需用 `{{`、`}}` 转义。

### f-string

最后一种（也是推荐）的格式化方法，直接在字符串前加 `f`，用 `{}` 内嵌变量：

```python
>>> r = 2.5
>>> s = 3.14 * r ** 2
>>> print(f'The area of a circle with radius {r} is {s:.2f}')
The area of a circle with radius 2.5 is 19.62
```

占位符同样是 `{}`，字面输出 `{`/`}` 时用 `{{`/`}}` 转义。

## list 列表

`list` 是有序的集合：

```python
>>> classmates = ['Michael', 'Bob', 'Tracy']
>>> classmates
['Michael', 'Bob', 'Tracy']
```

### 常用操作

- 用 `len()` 获得 list 元素的个数：

```python
>>> len(classmates)
3
```

- 用索引访问固定位置的元素，**索引从 0 开始**：

```python
>>> classmates[0]
'Michael'
>>> classmates[1]
'Bob'
>>> classmates[2]
'Tracy'
```

- 用 `-1` 作为索引直接取最后一个元素：

```python
>>> classmates[-1]
'Tracy'
```

同理 `-2` 是倒数第二个，`-3`、`-4` 依此类推。

- list 是**可变**有序表，可增删改：
  - `append()` 向末尾追加元素：

    ```python
    >>> classmates.append('Adam')
    >>> classmates
    ['Michael', 'Bob', 'Tracy', 'Adam']
    ```

  - `insert(index, x)` 把元素插入指定位置：

    ```python
    >>> classmates.insert(1, 'Jack')
    >>> classmates
    ['Michael', 'Jack', 'Bob', 'Tracy', 'Adam']
    ```

  - `pop()` 删除指定位置的元素，默认删除末尾：

    ```python
    >>> classmates.pop()
    'Adam'
    >>> classmates
    ['Michael', 'Jack', 'Bob', 'Tracy']
    ```

    ```python
    >>> classmates.pop(1)
    'Jack'
    >>> classmates
    ['Michael', 'Bob', 'Tracy']
    ```

- list 里的元素**数据类型可以不同**，甚至可以嵌套另一个 list（list 元素也是 list）。

## tuple 元组

`tuple` 也是一种有序列表，但与 list 不同：**tuple 一旦初始化就不能修改**（不可变）。

- 定义只有一个元素的元组时，必须加一个逗号：

```python
>>> t = (1,)
>>> t
(1,)
```

因为 `t = (1)` 会被当作给变量 `t` 赋值数字 `1`——`()` 被看作数学运算符。

- 元组的元素可以是可变对象。例如元组内包含 list 时，该 list 的内容可以修改（元组本身仍未变）：

```python
>>> t = ('a', 'b', ['A', 'B'])
>>> t[2][0] = 'X'
>>> t[2][1] = 'Y'
>>> t
('a', 'b', ['X', 'Y'])
```

## 条件判断

经典的 `if / elif / else` 结构：

```python
if <条件判断1>:
    <执行1>
elif <条件判断2>:
    <执行2>
elif <条件判断3>:
    <执行3>
else:
    <执行4>
```

> **注意**：`input()` 返回的数据类型是 `str` 字符串，进行运算和判断前要先转换为正确的数据类型：

```python
s = input('birth: ')
birth = int(s)
if birth < 2000:
    print('00前')
else:
    print('00后')
```

## 模式匹配（match）

针对某个变量匹配若干种情况，可以使用 `match` 语句：

```python
score = 'B'

match score:
    case 'A':
        print('score is A.')
    case 'B':
        print('score is B.')
    case 'C':
        print('score is C.')
    case _:   # _ 表示匹配到其他任何情况
        print('score is ???.')
```

`match` 除了匹配简单的单个值，还可以匹配**多个值、一定范围**，并把匹配到的值绑定到变量：

```python
age = 15

match age:
    case x if x < 10:
        print(f'< 10 years old: {x}')
    case 10:
        print('10 years old.')
    case 11 | 12 | 13 | 14 | 15 | 16 | 17 | 18:
        print('11~18 years old.')
    case 19:
        print('19 years old.')
    case _:
        print('not sure.')
```

`match` 还可以匹配**列表**：

```python
args = ['gcc', 'hello.c', 'world.c']
# args = ['clean']
# args = ['gcc']

match args:
    # 仅出现 gcc，报错:
    case ['gcc']:
        print('gcc: missing source file(s).')
    # 出现 gcc，且至少指定了一个文件:
    case ['gcc', file1, *files]:
        print('gcc compile: ' + file1 + ', ' + ', '.join(files))
    # 仅出现 clean:
    case ['clean']:
        print('clean')
    case _:
        print('invalid command.')
```

## 循环

Python 的循环有两种：`for...in` 和 `while`。

### for...in 循环

```python
names = ['Michael', 'Bob', 'Tracy']
for name in names:
    print(name)
```

`for x in ...` 循环把每个元素带入变量 `x`，然后执行缩进块里的语句。

- `range()` 生成整数序列，可用 `list()` 转换为 list：

```python
>>> list(range(5))
[0, 1, 2, 3, 4]
```

- `for x in ...` 也可以直接对 `range()` 使用：

```python
sum = 0
for x in range(101):
    sum = sum + x
print(sum)
```

### while 循环

只要条件满足就不断循环，条件不满足时退出：

```python
sum = 0
n = 99
while n > 0:
    sum = sum + n
    n = n - 2
print(sum)
```

- `break` 语句可以**提前退出**循环。
- `continue` 语句可以**跳过当前循环**、进入下一轮。

> 不要滥用 `break` 和 `continue` 语句，滥用会造成代码执行逻辑分叉过多；大多数循环不需要用到它们。

## dict 字典

`dict` 是字典（dictionary），在其他语言里也叫 map，使用**键值（key-value）**存储，查找速度极快：

```python
>>> d = {'Michael': 95, 'Bob': 75, 'Tracy': 85}
>>> d['Michael']
95
```

- 往 dict 里通过 key 放入数据：

```python
>>> d['Adam'] = 67
>>> d['Adam']
67
```

- 用 `in` 判断 key 是否存在：

```python
>>> 'AAA' in d
False
```

- 或用 dict 自带的 `get()` 方法，key 不存在时返回 `None`（不会报错）：

```python
>>> d.get('Thomas')
```

- 删除一个 key 用 `pop(key)`，对应的 value 也会一并删除：

```python
>>> d.pop('Bob')
75
>>> d
{'Michael': 95, 'Tracy': 85}
```

> dict 适用于需要高速查找的场景，在 Python 代码中几乎无处不在。**第一条要牢记的：dict 的 key 必须是不可变对象**——所以 list 不能作为 key。

## set 集合

`set` 是一组 key 的集合，但**不存储 value**；由于 key 不能重复，set 中没有重复元素。

- 用 `{x, y, z, ...}` 创建：

```python
>>> s = {1, 2, 3}
>>> s
{1, 2, 3}
```

- 或提供一个 list 作为输入集合：

```python
>>> s = set([1, 2, 3])
>>> s
{1, 2, 3}
```

- `add()` 添加元素：

```python
>>> s.add(4)
>>> s
{1, 2, 3, 4}
```

- `remove()` 删除元素：

```python
>>> s.remove(4)
>>> s
{1, 2, 3}
```

- set 可看作数学意义上的集合（无序、无重复），因此能做交集、并集等运算：

```python
>>> s1 = {1, 2, 3}
>>> s2 = {2, 3, 4}
>>> s1 & s2
{2, 3}
>>> s1 | s2
{1, 2, 3, 4}
```

## 关于不可变对象

对不可变对象来说，调用对象自身的任何方法**都不会改变该对象的内容**，而是创建一个新的对象并返回。

## 总结：如何选择数据结构

- 需要存储一组数据？
  - 需要键值对映射？ → **字典 dict**
  - 只需要存储元素？
    - 元素需要唯一？ → **集合 set**
    - 元素可重复？
      - 需要修改（增/删/改）？ → **列表 list**
      - 不需要修改（只读保护）？ → **元组 tuple**
