# Python 定制类：`__str__`、`__iter__`、`__getitem__`、`__getattr__`、`__call__`

Python 的类可以定义 `__xxx__` 特殊方法，让实例表现出内置类型那样的行为（打印、迭代、按下标取值、像函数一样调用等），这类类称为**定制类**。

## `__str__` 与 `__repr__`：打印 / 展示实例

- `print()`、`str()` 调用 `__str__`；交互环境直接看实例调用 `__repr__`。
- 默认输出 `<__main__.Student object at 0x...>`，可自定义：

```python
class Student(object):
    def __init__(self, name):
        self.name = name
    def __str__(self):
        return 'Student object (name: %s)' % self.name
    __repr__ = __str__    # 偷懒写法：repr 复用 str

>>> print(Student('Michael'))
Student object (name: Michael)
>>> Student('Michael')    # 直接看实例，也显示友好内容
Student object (name: Michael)
```

## `__iter__` 与 `__next__`：用于 for 循环

实现 `__iter__`（返回迭代对象）和 `__next__`（不断返回下一个值，结束抛 `StopIteration`），实例就能被 `for...in` 遍历：

```python
class Fib(object):
    def __init__(self):
        self.a, self.b = 0, 1          # 初始化两个计数器 a, b

    def __iter__(self):
        return self                    # 实例本身就是迭代对象，返回自己

    def __next__(self):
        self.a, self.b = self.b, self.a + b
        if self.a > 100000:            # 退出循环的条件
            raise StopIteration()
        return self.a

>>> for n in Fib():
...     print(n)
...
1
1
2
3
5
8
...
```

## `__getitem__`：像 list 一样按下标取值

只有 `__iter__` 还不能像 list 那样取第 5 个元素，需要实现 `__getitem__`：

```python
class Fib(object):
    def __getitem__(self, n):
        if isinstance(n, int):          # n 是索引
            a, b = 1, 1
            for x in range(n):
                a, b = b, a + b
            return a
        if isinstance(n, slice):        # n 是切片
            start, stop = n.start, n.stop
            if start is None:
                start = 0
            a, b, L = 1, 1, []
            for x in range(stop):
                if x >= start:
                    L.append(a)
                a, b = b, a + b
            return L

>>> Fib()[5]
8
>>> Fib()[:5]
[1, 1, 2, 3, 5]
```

> 同样还可以实现 `__setitem__`（按索引赋值）和 `__delitem__`（按索引删除），让类具备完整的 list 行为。

## `__getattr__`：访问不存在的属性时兜底

调用**不存在的属性**时自动调用 `__getattr__`，可返回默认值或动态构造：

```python
class Student(object):
    def __getattr__(self, attr):
        if attr == 'score':
            return 99
        raise AttributeError('Student has no attribute %s' % attr)

>>> s = Student()
>>> s.score    # 本来不存在，被 __getattr__ 拦截返回 99
99
```

利用它还能实现**链式调用**（如 REST API 风格）：

```python
class Chain(object):
    def __init__(self, path=''):
        self._path = path
    def __getattr__(self, path):
        return Chain('%s/%s' % (self._path, path))
    def __str__(self):
        return self._path
    __repr__ = __str__

>>> Chain().status.user.timeline.list
'/status/user/timeline/list'
```

## `__call__`：实例像函数一样调用

实现 `__call__` 后，实例本身可以直接加括号调用（`self` 参数不用传）：

```python
class Student(object):
    def __init__(self, name):
        self.name = name
    def __call__(self):
        print('My name is %s.' % self.name)

>>> s = Student('Michael')
>>> s()                       # 直接像函数一样调用实例
My name is Michael.
```

用 `callable(s)` 可以判断一个对象能否被调用（返回 `True`/`False`）。
