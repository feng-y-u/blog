# Python IO 编程

程序运行时，变量都在内存里，程序一结束就被操作系统回收。要把数据**留住**（存到磁盘）或者**传给别人**（跨程序、跨语言），就需要 IO：读写文件、操作目录、把对象序列化。

## 文件的读写

读写文件，本质上是**请求操作系统打开一个文件对象**，然后通过操作系统提供的接口从这个文件对象中读取或写入。

### 读文件

要以读文件的模式打开一个文件对象，使用 Python 内置的 `open()` 函数，传入文件名和标志符：

```python
>>> f = open('C:/Users/FLOW/Documents/test.txt', 'r')
>>> f.read()
'绀轰緥鏂囨湰'                      # 没有指定编码 → 中文乱码
>>> f = open('C:/Users/FLOW/Documents/test.txt', 'r', encoding='utf-8')
>>> f.read()
'示例文本'
```

使用 `read()` 可以读取文件内容，Python 把内容读到内存里；也可以指定编码。

> **注意**：`open()` 不传 `encoding` 时，用的是**平台默认编码**（Windows 上通常是 GBK 等本地编码）。拿它去读一个 UTF-8 文件，就会出现上面那种乱码。所以**打开文本文件时最好显式写上 `encoding='utf-8'`**。

### 写文件

写文件和读文件一样，只是模式换成 `'w'`（覆盖）或 `'a'`（追加）：

```python
with open('test.txt', 'w', encoding='utf-8') as f:
    f.write('示例文本\n第二行\n')

with open('test.txt', 'a', encoding='utf-8') as f:
    f.write('追加行\n')            # 'a' 模式在末尾追加，'w' 模式会清空原内容
```

- `'w'` 模式：文件不存在就创建，存在就**清空**后重写；
- `'a'` 模式：在文件末尾追加；
- `write()` 返回的是**写入的字符数**（写文件时通常用不到这个返回值）。

### 关闭文件：close、try...finally、with

文件使用完毕后必须调用 `close()` 方法关闭，不然会占用操作系统的资源。

为了保证**无论是否出错**都能正确关闭文件，一般使用 `try...finally`：

```python
try:
    f = open('/path/to/file', 'r')
    print(f.read())
finally:
    if f:
        f.close()
```

Python 引入了 `with` 语句，会自动调用 `close()` 方法：

```python
with open('/path/to/file', 'r') as f:
    print(f.read())
```

`with...as` 使用了**上下文管理器**：代码块执行完毕后自动关闭文件，而且**不受异常影响**（中途抛异常也会关）。

### 几种读取方式

- `read()`：一次性读取文件的**全部**内容（文件很大时会把内存吃满）；
- `read(size)`：每次最多读取 `size` 个字符（文本模式下按**字符**算，二进制模式下按字节算）；
- `readlines()`：一次读取所有内容，并**按行返回一个 list**；
- `for line in f:`：逐行读取，最省内存，适合大文件。

```python
>>> f = open('test.txt', 'r', encoding='utf-8')
>>> f.readlines()
['示例文本\n', '第二行\n']
>>> f.read(2)
'示例'
>>> for line in f:      # 逐行读，内存占用小
...     print(line.strip())
```

### file-like Object

有 `read()` 方法的对象都叫做 **file-like Object**。

`StringIO` 就是在内存中创建的文件对象，常用作临时缓冲。

### 编码不规范的文件的处理

有些文件编码不规范，读的时候可能报 `UnicodeDecodeError`。`open()` 可以接收一个 `errors` 参数，表示遇到编码错误后要如何处理：

```python
>>> f = open('/Users/michael/gbk.txt', 'r', encoding='gbk', errors='ignore')
```

`errors='ignore'` 表示直接忽略无法解码的字符（默认值是 `'strict'`，也就是报错）。

### 二进制文件

要读取图片、视频、Word 等二进制文件，用 `'rb'` 模式打开：

```python
>>> f = open('/Users/michael/test.jpg', 'rb')
>>> f.read()
b'\xff\xd8\xff\xe1\x00\x18Exif\x00\x00...'    # 十六进制表示的字节
```

`'rb'` 模式下 `read()` 返回的是 `bytes`，不需要（也不能）指定编码。

### 常用模式

| 模式 | 含义 |
| --- | --- |
| `'r'` | 只读，文件必须存在，文本模式 |
| `'w'` | 只写，清空原文件，不存在则创建 |
| `'a'` | 追加写，在文件末尾添加内容 |
| `'x'` | 独占创建，文件已存在则报错 |
| `'b'` | 二进制模式，比如 `'rb'`、`'wb'` |
| `'t'` | 文本模式，默认 |
| `'+'` | 可读可写，比如 `'r+'` |

## StringIO 和 BytesIO

### StringIO：在内存中读写 str

要把 str 写入 `StringIO`，需要先创建一个 `StringIO`，然后像文件一样写入：

```python
>>> from io import StringIO
>>> f = StringIO()
>>> f.write('hello')
5
>>> f.write(' ')
1
>>> f.write('world!')
6
>>> print(f.getvalue())
hello world!
```

`write()` 的返回值是写入的字符数，和写文件一致；`getvalue()` 用来取出写入的内容。

### 读取 StringIO

要读取 `StringIO`，可以用一个 str 初始化它，然后像读文件一样操作：

```python
>>> from io import StringIO
>>> f = StringIO('Hello!\nHi!\nGoodbye!')
>>> while True:
...     s = f.readline()
...     if s == '':
...         break
...     print(s.strip())
...
Hello!
Hi!
Goodbye!
```

### BytesIO：在内存中读写 bytes

`BytesIO` 与 `StringIO` 同理，只是读写的是 `bytes`：

```python
>>> from io import BytesIO
>>> b = BytesIO()
>>> b.write('中文'.encode('utf-8'))
6
>>> b.getvalue()
b'\xe4\xb8\xad\xe6\x96\x87'
```

## 操作文件和目录

Python 内置的 `os` 模块可以直接调用操作系统提供的接口函数。

### 系统类型与环境变量

用 `os.name` 查看操作系统类型：

```python
>>> import os
>>> os.name
'nt'        # Windows
>>> os.name
'posix'     # Linux、Unix 或 macOS
```

操作系统中定义的环境变量，全部保存在 `os.environ` 这个变量中，可以直接查看。要获取某个环境变量的值，可以调用 `os.environ.get('key')`：

```python
>>> os.environ.get('PATH')
'/usr/bin:/bin:/usr/sbin:/sbin:/usr/local/bin:/opt/X11/bin:/usr/local/mysql/bin'
>>> os.environ.get('x', 'default')    # 查找环境变量 x，找不到返回 default
'default'
```

### 路径操作

操作文件和目录的函数一部分放在 `os` 模块里，一部分放在 `os.path` 模块中：

```python
>>> os.path.abspath('.')                          # 查看当前目录的绝对路径
'/Users/michael'
>>> os.path.join('/Users/michael', 'testdir')     # 拼接路径，能正确处理不同系统的分隔符
'/Users/michael/testdir'
>>> os.mkdir('/Users/michael/testdir')            # 创建一个目录
>>> os.rmdir('/Users/michael/testdir')            # 删掉一个目录
```

> **注意**：拼接路径时**不能直接拼字符串**——Windows 用 `\`、Linux 用 `/`，直接拼会出错，要用 `os.path.join()`。
> 同理，拆分路径也不能直接拆字符串，要用 `os.path.split()`，它把路径拆成两部分，后一部分是最后一级：

```python
>>> os.path.split('/Users/michael/testdir/file.txt')
('/Users/michael/testdir', 'file.txt')
```

`os.path.splitext()` 可以直接拿到文件扩展名：

```python
>>> os.path.splitext('/path/to/file.txt')
('/path/to/file', '.txt')
```

### 文件操作

```python
os.rename('test.txt', 'test.py')    # 对文件重命名
os.remove('test.py')                # 删除文件
```

`shutil` 模块提供了 `copyfile()` 函数用来复制文件，可以把 `shutil` 模块看作 `os` 模块的补充。

### 列出目录

```python
[x for x in os.listdir('.') if os.path.isdir(x)]
```

这段代码可以列出当前目录下的**所有目录**，拆开看是三部分：

- `os.listdir('.')`：返回当前目录下所有文件和文件夹名称组成的 list；
- `os.path.isdir(x)`：判断 `x` 是不是一个目录；
- `[x for x in ... if ...]`：**列表推导式**，格式是 `[结果 for 变量 in 数据 if 条件]`，把满足条件的元素挑出来。

## 序列化：pickle

在程序运行的过程中，所有的变量都在内存中，比如一个 dict：

```python
d = dict(name='Bob', age=20, score=88)
```

可以随时修改变量（比如把 name 改成 'Bill'），但是**一旦程序结束，变量占用的内存就被操作系统全部回收**；如果没有把修改后的数据存到磁盘上，下次重新运行时变量又会回到初始值。

- 把变量从内存中变成**可存储或传输**的过程，称为**序列化**，Python 中叫 **pickling**；
- 反过来，把变量内容从序列化的对象重新读到内存里，称为**反序列化**，即 **unpickling**。

Python 提供了 `pickle` 模块来实现序列化：

```python
>>> import pickle
>>> d = dict(name='Bob', age=20, score=88)
>>> pickle.dumps(d)          # 把任意对象序列化成一个 bytes
b'\x80\x04\x95$\x00\x00\x00\x00\x00\x00\x00}\x94(\x8c\x04name\x94\x8c\x03Bob\x94\x8c\x03age\x94K\x14\x8c\x05score\x94KXu.'
```

拿到 `bytes` 之后可以写入文件；也可以用 `pickle.dump()` 直接写入一个 file-like Object：

```python
>>> f = open('dump.txt', 'wb')
>>> pickle.dump(d, f)
>>> f.close()
```

反序列化时，可以先把内容读成 `bytes` 再用 `pickle.loads()`，也可以直接用 `pickle.load()` 从 file-like Object 里读：

```python
>>> f = open('dump.txt', 'rb')
>>> d = pickle.load(f)
>>> f.close()
>>> d
{'name': 'Bob', 'age': 20, 'score': 88}
```

> **PS**：pickle 只能用于 Python，而且不同版本的 Python 之间可能互不兼容——上面的字节内容就跟 Python 版本（pickle 协议）有关，换个版本可能完全不同。
> 另外，**不要用 `pickle.load()` 去加载来源不可信的数据**：反序列化过程本身可以执行任意代码。

## JSON

要在**不同的编程语言之间**传递对象，就必须把对象序列化为标准格式，比如 XML 或 JSON。JSON 实际上就是一个字符串，可以被所有语言读取，比 XML 更快，而且可以直接在 Web 页面中读取。

JSON 表示的对象就是标准的 JavaScript 语言的对象，和 Python 的类型对应关系如下：

| JSON 类型 | Python 类型 |
| --- | --- |
| `{}` | dict |
| `[]` | list |
| `"string"` | str |
| `1234.56` | int 或 float |
| `true` / `false` | True / False |
| `null` | None |

### 基本转换

Python 内置的 `json` 模块提供了 Python 对象到 JSON 格式的转换：

```python
>>> import json
>>> d = dict(name='Bob', age=20, score=88)
>>> json.dumps(d)
'{"name": "Bob", "age": 20, "score": 88}'
```

`json.dumps()` 返回一个 **str**，内容就是标准 JSON；`json.dump()` 方法同样可以把它写入一个 file-like Object。

把 JSON 反序列化为 Python 对象，使用 `loads()` 或对应的 `load()`：

```python
>>> json_str = '{"age": 20, "score": 88, "name": "Bob"}'
>>> json.loads(json_str)
{'age': 20, 'score': 88, 'name': 'Bob'}
```

### JSON 进阶：序列化自定义对象

Python 的 dict 可以直接序列化为 JSON 的 `{}`，但一般情况下，用 class 表示对象更为常用：

```python
import json

class Student(object):
    def __init__(self, name, age, score):
        self.name = name
        self.age = age
        self.score = score

s = Student('Bob', 20, 88)
```

`Student` 对象不是一个可直接序列化为 JSON 的对象，这时要用 `dumps()` 的 **`default` 参数**：当 `json.dumps()` 遇到自己不会处理的对象时，就会自动调用 `default` 指定的函数，由这个函数负责把对象转成可序列化的形式。

我们只需要为 `Student` 专门写一个转换函数，再把它传进去：

```python
def student2dict(std):
    return {
        'name': std.name,
        'age': std.age,
        'score': std.score
    }

>>> print(json.dumps(s, default=student2dict))
{"name": "Bob", "age": 20, "score": 88}
```

这样 `Student` 的实例首先会被函数转换成 dict，然后再被序列化为 JSON。

> **偷懒写法**：如果不想为每个类都写转换函数，可以**把实例的 `__dict__` 直接拿出来**——它本来就存着实例的所有属性：

```python
>>> print(json.dumps(s, default=lambda obj: obj.__dict__))
{"name": "Bob", "age": 20, "score": 88}
```

### 反序列化：object_hook

反序列化同理：先用 `loads()` 换出一个 dict 对象，再定义一个把 dict 转换成 `Student` 实例的函数，通过 **`object_hook`** 参数传进去：

```python
def dict2student(d):
    return Student(d['name'], d['age'], d['score'])

>>> json_str = '{"age": 20, "score": 88, "name": "Bob"}'
>>> print(json.loads(json_str, object_hook=dict2student))
<__main__.Student object at 0x10cd3c190>
```

### 中文与 ensure_ascii

对中文进行 JSON 序列化时，`json.dumps()` 还提供了一个 `ensure_ascii` 参数：

```python
import json

obj = dict(name='小明', age=20)
s = json.dumps(obj, ensure_ascii=True)
```

> `ensure_ascii` **默认为 `True`**：中文会被转义成 `\uXXXX` 的形式（`"小明"` → `"\u5c0f\u660e"`）；
> 只有写成 `ensure_ascii=False` 时，输出里才会保留中文字符。

```python
>>> json.dumps(obj)
'{"name": "\\u5c0f\\u660e", "age": 20}'
>>> json.dumps(obj, ensure_ascii=False)
'{"name": "小明", "age": 20}'
```
