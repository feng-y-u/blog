# Python 正则表达式

对字符串进行操作的需求几乎无处不在。**正则表达式**就是用来匹配字符串的表达式，它的设计思想是：用一种描述性的语言给字符串**定义规则**。

比如判断一个字符串是否是合法的 Email，要做两件事：

1. 创建一个匹配 Email 的正则表达式；
2. 用该正则表达式去匹配**用户的输入**，以此判断是否合法。

## 基础匹配规则

在正则表达式中，如果**直接给出字符，就是精确匹配**。用 `\d` 可以匹配一个数字，`\w` 可以匹配一个字母或数字：

```text
'00\d'   可以匹配 '007'
'\d\d\d' 可以匹配 '010'
'\w\w\d' 可以匹配 'py3'
```

`.` 可以匹配**任意一个字符**，所以 `'py.'` 可以匹配 `'pyc'`、`'pyo'`、`'py!'` 等等。

> **注意**：`.` 默认**不匹配换行符**。实测 `re.match(r'py.', 'py\n')` 返回 `None`，要匹配换行得加上 `re.S`（DOTALL）：`re.match(r'py.', 'py\n', re.S)` 才会成功。

### 量词：控制"前面的字符"出现几次

| 写法 | 含义 |
| --- | --- |
| `*` | 任意个（包括 0 个） |
| `+` | 至少一个 |
| `?` | 0 个或 1 个 |
| `{n}` | 恰好 n 个 |
| `{n,m}` | n 到 m 个 |

```python
>>> re.match(r'^ab*c$', 'ac').group()      # * 可以是 0 个
'ac'
>>> re.match(r'^ab+c$', 'abbbc').group()
'abbbc'
>>> re.match(r'^ab?c$', 'ac').group()
'ac'
>>> re.match(r'^a{2}$', 'aa').group()
'aa'
>>> re.match(r'^a{2,4}$', 'aaa').group()
'aaa'
```

> 量词修饰的是**它前面那个字符**（或分组），不是整段字符串。

### 更精确的匹配：`[]` 表示范围

```text
[0-9a-zA-Z\_]                可以匹配一个数字、字母或者下划线
[0-9a-zA-Z\_]+               可以匹配至少由一个数字、字母或者下划线组成的字符串
[a-zA-Z\_][0-9a-zA-Z\_]{0,19} 可以匹配由字母或下划线开头，后接 0 到 19 个数字、字母或下划线组成的字符串
```

> ⚠️ **`{0,19}` 里面千万不要写空格**。我实测过：写成 `{0, 19}`（逗号后带空格）时，Python **不报错**，但这个花括号会被当成**普通字符**去匹配字面量 `{0, 19}`，于是模式永远匹配不上：
>
> ```python
> >>> bool(re.match(r'^[a-z]{0,19}$', 'abc'))
> True
> >>> bool(re.match(r'^[a-z]{0, 19}$', 'abc'))
> False        # 静默失配，最难查的那种 bug
> ```

### 其他常用写法

- `A|B` 可以匹配 A 或 B；
- `^` 表示**行的开头**，`$` 表示**行的结束**；
- `\s` 表示一个空白字符（包括空格、TAB、换行等）。

## re 模块

Python 提供 `re` 模块，包含所有正则表达式的功能。

### 用 `r` 前缀写模式串

Python 本身的字符串也需要 `\` 转义，可读性不强，建议使用 Python 的 `r` 前缀，就不需要考虑转义：

```python
s = r'ABC\-001'      # Python 的字符串
# 对应的正则表达式字符串不变：'ABC\-001'
```

### re.match：判断是否匹配

`re.match(pattern, string)` 方法可以判断字符串与正则表达式是否匹配：匹配会返回一个 `Match` 对象，否则返回 `None`。

```python
test = '用户输入的字符串'
if re.match(r'正则表达式', test):
    print('ok')
else:
    print('failed')
```

> **注意 `match` 是从字符串开头开始匹配的**，不是"在整段文字里找"。所以上面这个判断才需要靠 `^...$` 或 `match` 本身来保证"整串都符合规则"：
>
> ```python
> >>> re.match(r'\d+', 'abc123')      # 开头不是数字，直接失败
> None
> >>> re.search(r'\d+', 'abc123')     # search 会扫描整串找第一个匹配
> <re.Match object; span=(3, 6), match='123'>
> ```
>
> 要在任意位置查找用 `re.search`，要"整串匹配"用 `^...$` 配合 `match`。

### 切分字符串

`re.split()` 可以按正则切分字符串。`\s` 表示一个空白字符（包括空格、TAB、换行等）：

```python
>>> re.split(r'\s+', 'a b   c')
['a', 'b', 'c']
```

加入 `,` 试试：

```python
>>> re.split(r'[\s\,]+', 'a,b, c  d')
['a', 'b', 'c', 'd']
```

再加入 `;`：

```python
>>> re.split(r'[\s\,\;]+', 'a,b;; c  d')
['a', 'b', 'c', 'd']
```

如果用户输入了一组标签，就可以用正则表达式把不规范输入转化成正确的数组。

### 分组：提取子串

正则表达式还可以提取子串，用 `()` 表示的就是要提取的**分组**：

```python
>>> m = re.match(r'^(\d{3})-(\d{3,8})$', '010-12345')
>>> m
<re.Match object; span=(0, 9), match='010-12345'>
>>> m.group(0)
'010-12345'
>>> m.group(1)
'010'
>>> m.group(2)
'12345'
```

模式 `^(\d{3})-(\d{3,8})$` 里两个括号的位置：

```text
^(\d{3})-(\d{3,8)}$
    ↑         ↑
  第1组      第2组
```

```python
m.group(0)   # 整个匹配结果
m.group(1)   # 第 1 个 ()
m.group(2)   # 第 2 个 ()
```

`groups()` 可以一次拿到所有分组：

```python
>>> t = '19:05:30'
>>> m = re.match(r'^(0[0-9]|1[0-9]|2[0-3]|[0-9])\:(0[0-9]|1[0-9]|2[0-9]|3[0-9]|4[0-9]|5[0-9]|[0-9])\:(0[0-9]|1[0-9]|2[0-9]|3[0-9]|4[0-9]|5[0-9]|[0-9])$', t)
>>> m.groups()
('19', '05', '30')
```

### 贪婪匹配

正则匹配**默认是贪婪匹配**，也就是尽可能多地匹配字符；在量词后面加一个问号，就变成**非贪婪匹配**（尽可能少匹配）：

```python
>>> re.match(r'^(\d+)(0*)$', '102300').groups()
('102300', '')          # \d+ 贪婪，把 0 也一起吞了，0* 只能匹配空串

>>> re.match(r'^(\d+?)(0*)$', '102300').groups()
('1023', '00')          # \d+? 非贪婪，只吃到不能吃为止，剩下的 00 交给 0*
```

### 编译

在 Python 中使用正则表达式时，`re` 模块内部会干两件事：

1. **编译**正则表达式——如果正则表达式字符串本身不合法，会在这里报错；
2. 用编译后的正则表达式去匹配字符串。

如果一个正则要被反复使用，可以用 `re.compile()` **预编译**，省掉每次匹配时的编译开销：

```python
>>> import re
>>> re_telephone = re.compile(r'^(\d{3})-(\d{3,8})$')      # 编译
>>> re_telephone.match('010-12345').groups()               # 使用
('010', '12345')
>>> re_telephone.match('010-8086').groups()
('010', '8086')
```

## 小结：判断 Email

回到开头那个问题，一个（简化版）Email 正则：

```python
import re

pattern = r'^[0-9a-zA-Z\_][0-9a-zA-Z\_]{0,19}@[0-9a-zA-Z]{1,15}\.[a-zA-Z]{1,5}$'

for s in ['someone@gmail.com', 'bill.gates@microsoft.com', 'bob#example.com']:
    print('%-26s ->' % s, bool(re.match(pattern, s)))
```

实测输出：

```text
someone@gmail.com          -> True
bill.gates@microsoft.com   -> False
bob#example.com            -> False
```

> **注意**：`bill.gates@microsoft.com` 是个完全合法的真实邮箱，却被判成 `False`——因为这个正则的"用户名"部分只允许字母、数字、下划线，**不允许点号**。这只是教学用的简化版本；实际项目里邮箱校验要么用更完整的正则，要么直接发验证邮件（能收到就是真的）。
