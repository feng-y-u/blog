# Python 基础（二）：list、tuple 与条件判断

## list 列表

`list` 是有序的集合：

```python
>>> classmates = ['Michael', 'Bob', 'Tracy']
>>> classmates
['Michael', 'Bob', 'Tracy']
```

### 常用操作

- 用 `len()` 获得 list 元素的个数：

```python
>>> len(classmates)
3
```

- 用索引访问固定位置的元素，**索引从 0 开始**：

```python
>>> classmates[0]
'Michael'
>>> classmates[1]
'Bob'
>>> classmates[2]
'Tracy'
```

- 用 `-1` 作为索引直接取最后一个元素：

```python
>>> classmates[-1]
'Tracy'
```

同理 `-2` 是倒数第二个，`-3`、`-4` 依此类推。

- list 是**可变**有序表，可增删改：
  - `append()` 向末尾追加元素：

    ```python
    >>> classmates.append('Adam')
    >>> classmates
    ['Michael', 'Bob', 'Tracy', 'Adam']
    ```

  - `insert(index, x)` 把元素插入指定位置：

    ```python
    >>> classmates.insert(1, 'Jack')
    >>> classmates
    ['Michael', 'Jack', 'Bob', 'Tracy', 'Adam']
    ```

  - `pop()` 删除指定位置的元素，默认删除末尾：

    ```python
    >>> classmates.pop()
    'Adam'
    >>> classmates
    ['Michael', 'Jack', 'Bob', 'Tracy']
    ```

    ```python
    >>> classmates.pop(1)
    'Jack'
    >>> classmates
    ['Michael', 'Bob', 'Tracy']
    ```

- list 里的元素**数据类型可以不同**，甚至可以嵌套另一个 list（list 元素也是 list）。

## tuple 元组

`tuple` 也是一种有序列表，但与 list 不同：**tuple 一旦初始化就不能修改**（不可变）。

- 定义只有一个元素的元组时，必须加一个逗号：

```python
>>> t = (1,)
>>> t
(1,)
```

因为 `t = (1)` 会被当作给变量 `t` 赋值数字 `1`——`()` 被看作数学运算符。

- 元组的元素可以是可变对象。例如元组内包含 list 时，该 list 的内容可以修改（元组本身仍未变）：

```python
>>> t = ('a', 'b', ['A', 'B'])
>>> t[2][0] = 'X'
>>> t[2][1] = 'Y'
>>> t
('a', 'b', ['X', 'Y'])
```

## 条件判断

经典的 `if / elif / else` 结构：

```python
if <条件判断1>:
    <执行1>
elif <条件判断2>:
    <执行2>
elif <条件判断3>:
    <执行3>
else:
    <执行4>
```

> **注意**：`input()` 返回的数据类型是 `str` 字符串，进行运算和判断前要先转换为正确的数据类型：

```python
s = input('birth: ')
birth = int(s)
if birth < 2000:
    print('00前')
else:
    print('00后')
```
