# Python 函数（三）：递归函数

## 什么是递归函数

在函数内部，可以调用其他函数。如果一个函数**在内部调用自身本身**，这个函数就是**递归函数**。

以计算阶乘 `n! = 1 × 2 × 3 × ... × n` 为例，用函数 `fact(n)` 表示，可以看出：

> `fact(n) = n! = (n-1)! × n = fact(n-1) × n`

所以 `fact(n)` 可以写成：

```python
def fact(n):
    if n == 1:
        return 1
    return n * fact(n - 1)
```

递归函数的**优点是定义简单，逻辑清晰**。理论上，所有的递归函数都可以写成循环的方式，但循环的逻辑不如递归清晰。

## 递归的两个要素

任何递归函数都只有两个零件：

```python
def 递归函数(问题):
    if 问题小到不用再拆:        # ① 出口（终止条件）——最重要
        return 直接答案
    else:                      # ② 递归式子——把问题变小
        return 用更小的同款问题算出答案
```

1. **终止条件（出口）**：问题小到不用再拆时直接返回，如上例的 `if n == 1: return 1`。**缺少出口的递归会无限调用下去，最终栈溢出。**
2. **递归式子**：把大问题拆成更小的同款问题，如上例的 `fact(n-1) × n`。

## 递归的执行过程："递"与"归"

> **理解技巧**：递归 = "递" + "归"。"递"是一层层往下调用（每层都在等待下一层的结果），"归"是触底之后结果一层层返回来。可以自己运行下面的小实验观察打印顺序：

```python
def countdown(n):
    if n == 0:
        print('BOOM!')
    else:
        print('倒计时:', n)
        countdown(n - 1)      # 递：调用自己
    print('返回本层:', n)      # 归：触底后一层层返回

countdown(3)
# 倒计时: 3 → 倒计时: 2 → 倒计时: 1 → BOOM! → 返回本层: 0 → 返回本层: 1 → 返回本层: 2 → 返回本层: 3
```

把 `fact(5)` 的计算过程展开，可以清楚看到"先递后归"：

```python
===> fact(5)
===> 5 * fact(4)
===> 5 * (4 * fact(3))
===> 5 * (4 * (3 * fact(2)))
===> 5 * (4 * (3 * (2 * fact(1))))
===> 5 * (4 * (3 * (2 * 1)))      # 触底，开始"归"
===> 5 * (4 * (3 * 2))
===> 5 * (4 * 6)
===> 5 * 24
===> 120
```

> 写递归跟做数学归纳法一样：**假设"更小的子问题已经能正确算出来"**，只要出口正确 + 拆法正确，整个函数就正确。人肉跟踪每一层是调试时才做的事。真想看过程，就去 [Python Tutor](https://pythontutor.com/) 把代码粘进去，它会一步步画栈帧的进出，看两遍就通了。

## 递归调用与栈

使用递归函数需要注意防止**栈溢出**。

计算机中，函数调用是通过**栈（stack）**这种数据结构实现的：每进入一个函数调用，栈就加一层**栈帧**；函数返回，栈就减一层栈帧。每次递归深入一层，就多一层栈帧被"挂起"等待，所以递归调用的次数过多，会导致栈溢出：

```python
>>> fact(1000)
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
  File "<stdin>", line 4, in fact
  ...
  File "<stdin>", line 4, in fact
RuntimeError: maximum recursion depth exceeded in comparison
```

## 尾递归

解决递归调用栈溢出的方法是使用**尾递归**优化。事实上尾递归和循环的效果是一样的，把循环看成一种特殊的尾递归函数也可以。

**尾递归**是指：在函数返回的时候调用自身本身，并且 return 语句**不能包含表达式**。这样，编译器或解释器就可以把尾递归做优化，使递归无论调用多少次，都**只占用一个栈帧**，不会出现栈溢出。

上面的 `fact(n)` 由于 `return n * fact(n - 1)` 引入了乘法表达式，所以不是尾递归。要改成尾递归，需要把每一步的乘积传入递归函数：

```python
def fact(n):
    return fact_iter(n, 1)

def fact_iter(num, product):
    if num == 1:
        return product
    return fact_iter(num - 1, num * product)
```

`return fact_iter(num - 1, num * product)` 仅返回递归函数本身：`num - 1` 和 `num * product` 在函数调用前就已经被计算好了，返回时没有多余表达式，符合尾递归定义。

> **注意**：Python 标准的解释器**并没有**针对尾递归做优化，任何递归函数都存在栈溢出的问题。尾递归更多是理解"优化思路"；实际写 Python 时，递归太深仍会爆栈，此时应改用循环。
