# Python 基础（三）：模式匹配、循环、dict 与 set

## 模式匹配（match）

针对某个变量匹配若干种情况，可以使用 `match` 语句：

```python
score = 'B'

match score:
    case 'A':
        print('score is A.')
    case 'B':
        print('score is B.')
    case 'C':
        print('score is C.')
    case _:   # _ 表示匹配到其他任何情况
        print('score is ???.')
```

`match` 除了匹配简单的单个值，还可以匹配**多个值、一定范围**，并把匹配到的值绑定到变量：

```python
age = 15

match age:
    case x if x < 10:
        print(f'< 10 years old: {x}')
    case 10:
        print('10 years old.')
    case 11 | 12 | 13 | 14 | 15 | 16 | 17 | 18:
        print('11~18 years old.')
    case 19:
        print('19 years old.')
    case _:
        print('not sure.')
```

`match` 还可以匹配**列表**：

```python
args = ['gcc', 'hello.c', 'world.c']
# args = ['clean']
# args = ['gcc']

match args:
    # 仅出现 gcc，报错:
    case ['gcc']:
        print('gcc: missing source file(s).')
    # 出现 gcc，且至少指定了一个文件:
    case ['gcc', file1, *files]:
        print('gcc compile: ' + file1 + ', ' + ', '.join(files))
    # 仅出现 clean:
    case ['clean']:
        print('clean')
    case _:
        print('invalid command.')
```

## 循环

Python 的循环有两种：`for...in` 和 `while`。

### for...in 循环

```python
names = ['Michael', 'Bob', 'Tracy']
for name in names:
    print(name)
```

`for x in ...` 循环把每个元素带入变量 `x`，然后执行缩进块里的语句。

- `range()` 生成整数序列，可用 `list()` 转换为 list：

```python
>>> list(range(5))
[0, 1, 2, 3, 4]
```

- `for x in ...` 也可以直接对 `range()` 使用：

```python
sum = 0
for x in range(101):
    sum = sum + x
print(sum)
```

### while 循环

只要条件满足就不断循环，条件不满足时退出：

```python
sum = 0
n = 99
while n > 0:
    sum = sum + n
    n = n - 2
print(sum)
```

- `break` 语句可以**提前退出**循环。
- `continue` 语句可以**跳过当前循环**、进入下一轮。

> 不要滥用 `break` 和 `continue` 语句，滥用会造成代码执行逻辑分叉过多；大多数循环不需要用到它们。

## dict 字典

`dict` 是字典（dictionary），在其他语言里也叫 map，使用**键值（key-value）**存储，查找速度极快：

```python
>>> d = {'Michael': 95, 'Bob': 75, 'Tracy': 85}
>>> d['Michael']
95
```

- 往 dict 里通过 key 放入数据：

```python
>>> d['Adam'] = 67
>>> d['Adam']
67
```

- 用 `in` 判断 key 是否存在：

```python
>>> 'AAA' in d
False
```

- 或用 dict 自带的 `get()` 方法，key 不存在时返回 `None`（不会报错）：

```python
>>> d.get('Thomas')
```

- 删除一个 key 用 `pop(key)`，对应的 value 也会一并删除：

```python
>>> d.pop('Bob')
75
>>> d
{'Michael': 95, 'Tracy': 85}
```

> dict 适用于需要高速查找的场景，在 Python 代码中几乎无处不在。**第一条要牢记的：dict 的 key 必须是不可变对象**——所以 list 不能作为 key。

## set 集合

`set` 是一组 key 的集合，但**不存储 value**；由于 key 不能重复，set 中没有重复元素。

- 用 `{x, y, z, ...}` 创建：

```python
>>> s = {1, 2, 3}
>>> s
{1, 2, 3}
```

- 或提供一个 list 作为输入集合：

```python
>>> s = set([1, 2, 3])
>>> s
{1, 2, 3}
```

- `add()` 添加元素：

```python
>>> s.add(4)
>>> s
{1, 2, 3, 4}
```

- `remove()` 删除元素：

```python
>>> s.remove(4)
>>> s
{1, 2, 3}
```

- set 可看作数学意义上的集合（无序、无重复），因此能做交集、并集等运算：

```python
>>> s1 = {1, 2, 3}
>>> s2 = {2, 3, 4}
>>> s1 & s2
{2, 3}
>>> s1 | s2
{1, 2, 3, 4}
```

## 关于不可变对象

对不可变对象来说，调用对象自身的任何方法**都不会改变该对象的内容**，而是创建一个新的对象并返回。

## 总结：如何选择数据结构

- 需要存储一组数据？
  - 需要键值对映射？ → **字典 dict**
  - 只需要存储元素？
    - 元素需要唯一？ → **集合 set**
    - 元素可重复？
      - 需要修改（增/删/改）？ → **列表 list**
      - 不需要修改（只读保护）？ → **元组 tuple**
