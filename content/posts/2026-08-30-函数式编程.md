# Python 函数式编程：返回函数、闭包、匿名函数、装饰器与偏函数

上一篇介绍了 `map/reduce`、`filter`、`sorted` 等高阶函数——**函数可以作为参数传入**。函数式编程还有几个重要特性：函数可以作为**结果返回**（返回函数与闭包）、匿名函数、装饰器和偏函数。

## 返回函数

高阶函数除了可以接受函数作为参数外，**还可以把函数作为结果返回**。

比如一个求和函数不需要立刻求和，就可以**不返回求和的结果，而是返回求和的函数**：

```python
def lazy_sum(*args):
    def sum():
        ax = 0
        for n in args:
            ax = ax + n
        return ax
    return sum
```

调用 `lazy_sum()` 后返回的是一个**求和函数**，要**再次调用**这个函数，才会真正计算结果：

```python
>>> f = lazy_sum(1, 3, 5, 7, 9)
>>> f()
25
```

每次调用 `lazy_sum()` 都会**返回一个新的函数**，即使传入的参数相同：

```python
>>> f1 = lazy_sum(1, 3, 5, 7, 9)
>>> f2 = lazy_sum(1, 3, 5, 7, 9)
>>> f1 == f2
False
```

## 闭包（Closure）

在一个函数中定义内部函数，并且内部函数可以**引用外部函数的参数和局部变量**。当 `lazy_sum` 返回函数 `sum` 时，**相关参数和变量都保存在返回的函数中**，这种程序结构称为**闭包**。

> 闭包 = 函数 + 它引用的外部环境。返回的函数"携带"了创建它时的外部变量。

**注意：返回闭包时，返回函数不要引用任何循环变量，或者后续会发生改变的量**——否则所有返回的函数，都会以**运行时变量的值**为准：

```python
def count():
    fs = []
    for i in range(1, 4):
        def f():
            return i * i
        fs.append(f)
    return fs

f1, f2, f3 = count()
>>> f1()
9
>>> f2()
9
>>> f3()
9
```

原因：`f1`、`f2`、`f3` 被调用时循环早已结束，三个函数引用的 `i` 都是循环结束时的值 `3`，所以结果都是 `9`。

如果一定要引用循环变量，方法是**再创建一个函数，用该函数的参数绑定循环变量当前的值**——无论该循环变量后续如何更改，已绑定到函数参数的值不变：

```python
def count():
    def f(j):
        def g():
            return j * j
        return g
    fs = []
    for i in range(1, 4):
        fs.append(f(i))    # f(i) 立刻被执行，因此 i 的当前值被传入 f()
    return fs

f1, f2, f3 = count()
>>> f1()
1
>>> f2()
4
>>> f3()
9
```

## nonlocal

使用闭包时，内层函数引用了外层函数的局部变量。如果只是**读**外层变量的值，没有什么问题；但如果直接**对外层变量赋值**，Python 解释器会把该变量当作内部函数的**局部变量**（赋值会"本地化"，导致修改不到外层变量甚至报错）。

想要在内部函数里修改外层函数的局部变量，需要在内部函数中加一个 `nonlocal` 声明：

```python
def inc():
    x = 0
    def fn():
        nonlocal x
        x = x + 1
        return x
    return fn

f = inc()

print(f())   # 1
print(f())   # 2
```

## 匿名函数（lambda）

Python 对匿名函数提供**有限支持**。**关键字 `lambda` 表示匿名函数**：

```python
>>> f = lambda x: x * x
>>> f
<function <lambda> at 0x1022ef630>
>>> f(5)
25
```

`lambda x: x * x` 实际上就是：

```python
def f(x):
    return x * x
```

lambda 冒号**前**的 `x` 表示**函数参数**，冒号**后**是表达式（省略了 `return`）。

匿名函数可以直接**作为返回值返回**：因为没有名字，不必担心函数名冲突：

```python
def build(x, y):
    return lambda: x * x + y * y
```

## 装饰器（Decorator）

在**代码运行期间动态增加功能**、又不修改函数定义的方式，称为"装饰器"。

先复习两个基础：

- **函数是对象，对象可以赋值给变量**，所以通过变量也能调用函数；
- 函数对象有一个 `__name__` 属性，可以拿到**函数的名字**：

```python
def hello():
    print('Hello, world!')

h = hello        # 把函数对象赋给变量
h()              # 通过变量调用

>>> hello.__name__
'hello'
>>> h.__name__
'hello'
```

如果要加强函数功能，但**又不希望修改函数定义**，就可以用装饰器。先写一个统计函数运行耗时的装饰器：

```python
import time

def timer(func):
    def wrapper(*args, **kwargs):          # *args, **kwargs 保证能装饰任何函数
        start_time = time.time()
        result = func(*args, **kwargs)     # 执行原函数
        end_time = time.time()
        print(f'Function {func.__name__} took {end_time - start_time:.6f} seconds to execute.')
        return result
    return wrapper
```

调用时使用**语法糖**：

```python
# 语法糖写法
@timer
def my_function():
    pass

# 完全等价于下面的普通写法
def my_function():
    pass
my_function = timer(my_function)
```

### 用 @wraps 保留原函数属性

直接写装饰器，会导致原函数的 `__name__`、`__doc__` 等属性被替换成 wrapper 的。只需在装饰器内部加上 `@wraps(func)`，但要先导入 `functools` 模块：

```python
import functools

def timer(func):
    @functools.wraps(func)                 # 保留原函数的 __name__、__doc__ 等属性
    def wrapper(*args, **kwargs):
        ...
        return result
    return wrapper
```

### 带参数的装饰器

如果装饰器**本身需要接受参数**，就需要**再套一层外层函数**：

```python
from functools import wraps

def logger(level="INFO"):
    def decorator(func):
        @wraps(func)
        def wrapper(*args, **kwargs):
            print(f"[{level}] 调用 {func.__name__}")
            return func(*args, **kwargs)
        return wrapper
    return decorator

@logger(level="ERROR")     # 注意这里调用了 logger（带括号）
def add(x, y):
    return x + y
```

等效于 `add = logger(level="ERROR")(add)`：

1. 先执行 `logger(level="ERROR")`，返回 `decorator` 函数；
2. 再执行 `decorator(add)`，返回 `wrapper` 函数。

## 偏函数（functools.partial）

设定函数参数的**默认值**可以降低函数调用的难度。比如 `int()` 函数可以将字符串转换为整数，它有一个默认参数 `base=10`（默认按十进制转换），所以可以传入 `base` 参数做 N 进制的转换：

```python
>>> int('12345', base=8)
5349
>>> int('12345', 16)
74565
```

但如果要转换一大批**二进制**字符串，每次都传 `base=2` 太麻烦，这时就可以创建一个偏函数：

```python
def int2(x, base=2):
    return int(x, base)
```

Python 的 `functools` 模块内置了 `partial`，可以帮助我们创建偏函数，**不需要自己定义 `int2()`**：

```python
>>> import functools
>>> int2 = functools.partial(int, base=2)
>>> int2('1000000')
64
>>> int2('1010101')
85
```

`functools.partial` 可以把一个函数的**特定参数固定**，并返回一个新函数。

创建偏函数时，可以接受**函数对象、`*args`、`**kw`** 这三种参数：

- 上面传入的 `base=2` 是 `**kw` 类型；
- 也可以传入 `*args` 类型，比如在 `max` 前固定一个参数 10：

```python
>>> max2 = functools.partial(max, 10)
>>> max2(5, 6, 7)
10
```

调用 `max2(5, 6, 7)` 时，会自动加一个值为 10 的参数，即等价于 `max(10, 5, 6, 7)`。

> **小结**：当函数的参数个数太多、需要简化时，使用 `functools.partial` 可以创建一个新的函数，这个新函数可以固定住原函数的部分参数，从而在调用时更简单。
